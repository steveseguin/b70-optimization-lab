# Rapid one-B70 model snapshots: shared prompt suite capsule

> **Certification: `record-capsule`.** This directory preserves only the
> strict realistic prompt suite (`realistic-suite-v1.json`) that every rapid
> one-B70 snapshot result references by `suite_id`. It is not an install or
> replay guide.

The suite is sent once per prompt as a cold response; headline rows require
`cached_tokens=0`. The measured results, per-model launch commands, and the
notes that explain each snapshot live in the
[rapid result ledger](../../results/rapid-model-snapshots-b70/README.md) and
the [rapid experiment notes](../../experiments/rapid-model-snapshots-b70/README.md);
the raw receipts are under [`data/rapid-model-snapshots-b70/`](../../data/rapid-model-snapshots-b70/).
