## Top three changes

1. **On the first fault of a boot, run the cheap hardware check before any
   software hypothesis.** AGENTS.md already requires halting on a fault ("record
   faults and halt new requests"); the gap is *what* runs next. Evidence: eleven
   freeze incidents (`a1c9afdf`→`164f585a`) were each halted then diagnosed in
   software before a memtester ran (`ebcd56cd`), by which point the boot was
   burned. Saving: days of churn (09-15–09-20) replaced by an early hardware
   signal. Generalizes: health check first, any lane/host, every fault.
2. **Give `efficiency-audit-metrics.py` a shallow-clone guard, and teach it the
   nested campaign schema — glob plus parser.** Evidence: this run's checkout was
   shallow (~50 commits, ~33h history); the first pass reported
   `campaigns_total: 421`, 0.0h median latency — a shallow-boundary artifact.
   Deepened, `campaigns_total` fell to 0: the glob only matches flat
   `data/*prereg*.json`, and LTX has nested `data/<campaign>/preregistration.json`
   since 09-13. Widening the glob alone isn't enough: `lane = prereg.parts[-3]`
   and the sibling `*result*.json` search assume flat depth, so a nested path
   resolves lane as `"data"` with an empty stem. Named 09-12, fix proposed 09-09,
   still unfixed. Saving: restores every signal this audit exists to produce.
   Generalizes to every future lane.
3. **Fix `public-closure-scanner.py`'s `release_assets()` and `PATH_RE`.** Evidence:
   `gh` is absent, so its bare `except: set()` turns "can't check" into "0 assets
   exist," producing 75 `missing_release_asset` false findings; `PATH_RE` still
   truncates paths (`repro/qwen35-`) within 46 `missing_path` findings, the bug
   09-12 diagnosed. Saving: separates real gaps (794 `host_path_hardcoded` hits)
   from noise. Generalizes to every future scan.
