1. **Stop the daily audit's branch-and-PR delivery; commit its report directly to `main`,** per this repo's
   own Main-Only Git Policy (`AGENTS.md:341-346`), which forbids exactly the "agent branches... accumulating

   corrective commits, nothing landed — a policy violation, not a merge-process gap. Saving: recovers
   two-plus weeks of recommendation work; stops manufacturing more unmerged branches. Generalizes to any
   process whose own mechanism conflicts with the repo's stated policy.

   Generalizes: a status file is only true if refreshed at resumption.
