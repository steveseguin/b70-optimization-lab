## Top three changes

1. **Extend campaign discovery to dated result-directories without a `*prereg*` file.** Evidence:
   `campaigns_total` fell 4→0 while ≥23 `research/tp/*-2026-10-2{8,9}/`, `*-10-3{0,1}/` directories each
   closed with a `RESULT.md` and same-day commit. Saving: restores throughput/latency reporting for a
   week where 99% of commits are invisible to the script. Generalizes: every lane so far (LTX,
   ctxkeeper, now `research/tp`) registers arms by dated directory plus commit prose, not
   `*prereg*`/`*result*` filenames — the discovery assumption is wrong, not any one lane.
2. **Write a retention note when a review session adds bulk evidence capture.** Evidence:
   `check-repository-hygiene.py` flags 35 large artifacts, 31 inside `pp4-review-2026-10-28/` (112 MB),
   none paired with the "why needed, how to restore" note AGENTS.md's hygiene section asks for. Saving:
   a sentence at commit time versus reconstructing rationale from 8,700 files later. Generalizes: any
   review session capturing per-request `.tar.gz`/`.jsonl.gz` evidence trips the same warnings unless
   the rationale ships with the capture.
3. **Give a hosted resident server a tracked handback line, not just a self-timeout.** Evidence: the
   four-card LAN server has held every card ~41 hours as of this audit (started 10-31 13:28 EDT), and
   repo-wide commits stopped 1.34 days ago. Owner-authorized, not a rule breach, but it is this
   window's largest zero-throughput stretch, unnamed as GPU time lost in `CURRENT.md`. Saving: a
   one-line "hosting started/ends" entry lets the next audit tell planned downtime from a stall.
   Generalizes: any lane that hosts and optimizes on the same cards needs this every time it hosts.
