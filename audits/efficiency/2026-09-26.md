## Top three changes

1. **Make the metrics script detect and refuse a shallow clone.** Evidence:
   this report's first draft. Saving: prevents future audits from running
   against incomplete history. Generalizes to any script reasoning over
   `git log` here.
2. **Run offline fault triage on the *first* crash/freeze**, before any
   reboot/retry — not the second (the stability rule already requires
   halting on fault one). Evidence: the shared-conditions table in
   `.../2026-09-20-freeze-1145-packet88-correction.md`, built only after
   freeze 3, applies equally to freeze 1. Saving: up to 2 packet-cycles.
   Generalizes rule 1 to hardware-fault diagnosis.

   step.** Evidence: packet 91's MP4-save-offload lever is "host-side
   change, zero numerics risk" (`2026-09-21-capacity-budget-24fps.md:44-88`),
   yet unimplemented after 5.1 idle days; `ltx25-b70` has no
   DO-NOT-REPEAT.md despite 7 freeze notes. Saving: recovers idle days as
   merged code. Generalizes to any lane hitting a human-reboot gate.
