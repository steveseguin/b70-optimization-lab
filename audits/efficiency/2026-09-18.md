## Top three changes

1. **Add `watchdog:.*hard LOCKUP` to every active fault watcher.**
   Evidence: `ltx25-b70`'s `serve.py`/`serve-speed.py`/`serve-encoder.py`
   each duplicate one pattern missing the lockup form that hid one of
   two identical 09-15 events; `kernel_fault_detector.py` (broader) is
   only used by health checkers, not launchers; `qwen38-27b-b70`
   runners use a third, unrelated pattern. No single shared edit point
   — each launcher needs its own fix, or real centralization.
2. **Make prereg discovery recursive and deduplicated by campaign id;
   add a shallow-clone guard.** Evidence: undercounted campaigns 4 vs
   ≤9 real (7 invisible to the flat glob, 2 duplicating an id); the
   shallow clone separately fabricated
   `commits_total`/`campaigns_total`/latency, reported every audit
   `2026-09-03`–`2026-09-12`.
3. **Have the script resolve each campaign's actual outcome artifact,
   not one filename pattern.** Evidence: line 113 globs only
   `{stem}*result*.json`, missing `stability-01/summary.json` and
   `encoder-screen-01` (outcome in `progress.json`).
