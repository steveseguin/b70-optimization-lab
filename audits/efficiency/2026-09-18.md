## Top three changes

1. **Add `watchdog:.*hard LOCKUP` to the shared GPU-fault fast-fail regex.**
   Evidence: `xe-lockup-incident-01.md` — two identical hard lockups
   09-15, one undetected since the pattern only matches `Fault
   response|CAT error|engine reset|GPU HANG|GuC.*reset|coredump` plus
   RCU/soft-lockup forms. Saving: faster detection of the freeze class
   behind the 09-17 ~8h idle-freeze stretch. Generalizes: every lane's
   launcher shares this pattern.
2. **Make the metrics script's prereg discovery recursive; add a
   shallow-clone guard.** Evidence: undercounted campaigns 4 vs ≥11 real
   preregs (7 invisible to the flat glob); a shallow clone separately
   fabricated `commits_total`/`campaigns_total`/latency — the same bug
   reported every audit `2026-09-03` through `2026-09-12`, unfixed 6+
   runs. Saving: no manual re-derivation each week. Generalizes to every
   future week and lane using the newer subdirectory layout.
3. **Standardize the outcome field across campaign result files.**
   Evidence: `ltx25-b70`'s 4 nested campaigns used 3 shapes this week —
   `result.json` with `status`, `summary.json` with a free-text `status`
   sentence, `summary.json` with no status keys (`encoder-screen-01`,
   `2026-09-15-metadata-tweak-screen`). Saving: a script keying off
   `status`/`decision`/`classification` silently drops non-conforming
   campaigns, hiding real throughput. Generalizes to every lane.
