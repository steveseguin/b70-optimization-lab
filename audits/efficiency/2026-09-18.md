## Top three changes

1. **Add `watchdog:.*hard LOCKUP` to every active fault watcher.**
   Evidence: `serve.py`/`serve-speed.py`/`serve-encoder.py` each
   duplicate one pattern missing the lockup form that hid one of two
   identical 09-15 events; `kernel_fault_detector.py` (broader) is
   only used by health checkers, not launchers; `qwen38-27b-b70`
   runners use a third pattern. No single shared edit point. Saving:
   catches the freeze class costing hours this week. Generalizes to
   every lane's launchers once each is touched.
2. **Make prereg discovery recursive and deduplicated by campaign id;
   add a shallow-clone guard.** Evidence: undercounted campaigns 4 vs
   ≤9 real; shallow clone fabricated `commits_total`/latency, reported
   every audit `2026-09-03`–`2026-09-12`. Saving: no manual
   re-derivation weekly. Generalizes to every future week and lane.
3. **Have the script resolve each campaign's actual outcome artifact,
   not one filename pattern.** Evidence: line 113 misses
   `stability-01/summary.json` and `encoder-screen-01`
   (`progress.json`). Saving: recovers latency/outcome data now
   silently dropped. Generalizes to every non-`result.json` lane.
