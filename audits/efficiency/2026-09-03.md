## Top three changes

1. **Add a host heartbeat/watchdog independent of the journal poller.**
   Evidence: A8 and A57 are both journal-less freezes; A57's note names
   three more this window. Saving: recovers the lost time per freeze.
   Generalizes: any lane can freeze; a watchdog is infrastructure, not a
   per-model fix.
2. **Gate layer/component bisection on a prior kernel-census run for that
   shape.** Evidence: R64-R116 is the exact pattern rule 1 closed; its
   census took twenty minutes on one card. Saving: AGENTS.md's rule-1 note
   says the resulting three-day saga "settled in an evening" once census
   ran first. Generalizes: the failure signature is model-independent.
3. **Fix the outcome classifier/result-matching and make the closure
   scanner offline-safe.** Evidence: three bugs inflate `accepted`; 19
   phantom closure findings came from a missing `gh`. Saving: future
   audits stop re-discovering the same false positives. Generalizes: any
   read-only run of these audit inputs is hit.
