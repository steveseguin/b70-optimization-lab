## Top three changes

1. **Add a host heartbeat/watchdog independent of the per-server journal
   poller.** Evidence: A8 and A57 are both journal-less freezes per their
   own notes; A57's note names three more this window. Saving: recovers
   the lost time per undetected freeze. Generalizes: any lane on this rack
   can freeze this way; a watchdog is infrastructure, not a per-model fix.
2. **Gate layer/component bisection commits on a prior kernel-census run
   for that shape.** Evidence: D8-D14 is the exact pattern rule 1 closed;
   the census that solved it took twenty minutes on one card per
   `DO-NOT-REPEAT.md`. Saving: hours collapse to minutes, as R151-R166
   then showed. Generalizes: the failure signature is model-independent.
3. **Make the closure scanner usable by a read-only/offline auditor.**
   Evidence: this run manufactured 19 false findings because `gh` isn't
   installed and `release_assets()` (`public-closure-scanner.py:59-66`)
   silently returns empty on any lookup failure. Saving: avoids future
   audits re-reporting this phantom gap. Generalizes: any offline run of
   this required input is affected, not just this package.
