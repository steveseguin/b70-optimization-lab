## Top three changes

1. **Check `git rev-parse --is-shallow-repository` before trusting any
   `--since` window, in this script and in any future audit.** A shallow
   clone silently truncates history at an arbitrary commit that looks like
   a root; this cost the entire prior review cycle before a reviewer's
   independently-run count (192, not 50) forced `git fetch --unshallow`.
   Generalizes to any tool or agent reasoning over "the last N days" of git
   history in a freshly cloned sandbox.
2. **Write one fault-classification runbook the human follows for LTX, not
   an automated runner** — the stability constraints ban host-controlled
   benchmark wrappers outright. Packets 77–90 each cost a human
   investigation before the next launch; a written symptom→next-packet
   decision tree cuts that time with zero automation.
3. **Run the closure scanner on a candidate before it accumulates more
   evidence.** The 12 packages above carry real findings — cheaper to fix
   now than at promotion time.
