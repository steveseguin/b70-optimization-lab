## Top three changes

1. **Give the LTX lane one supervised runner that detects a freeze/fault
   and aborts fast with a clear report, leaving any reboot to the user
   — not a human manually diagnosing each symptom (VAE-gate latch, muxer
   error, capture refusal) before launching the next numbered packet.**
   Packets 77–90 (current evidence) were each a manual restart; rule 4's
   runner-owns-preflight/abort design shortens the diagnose step without
   touching the no-automatic-reboot rule — generalizing to any host that
   freezes under load.
2. **Extend the metrics script's scan to notes files, not just widen its
   regexes.** It only reads a result JSON's `status`/`decision`/
   `classification`, never `notes/*.md`, so it can't see events recorded
   only in prose (`DO-NOT-REPEAT.md` rows 26–27). Generalizes to every
   lane; it detects nothing today.
3. **Run the closure scanner on a candidate before it accumulates more
   evidence.** The 12 packages above carry `host_path_hardcoded` or
   `missing_release_asset` findings — cheaper to fix now than at
   `$publish-model-package` time.
