## Top three changes

1. **Unshallow before trusting `campaigns_total`/latency.** Evidence: this
   audit's own clone was shallow; `--diff-filter=A` grafted `8c4fcb96` as a
   fake root, inflating `campaigns_total` to 421 with 0h latency artifacts
   and hiding 55 real commits. Saving: have
   `scripts/efficiency-audit-metrics.py` call
   `git rev-parse --is-shallow-repository` and unshallow (or fail loud) before
   computing anything from `--diff-filter=A`. Generalizes to every future run
   in a fresh container clone, not just this one.

2. **Fix `commits_by_author`: reports 100% "claude", git author is 100%
   "Codex Agent".** Evidence: `author_class()` overrides the real author on
   any `Co-Authored-By: Claude` trailer, which `AGENTS.md`'s Cross-Agent
   Delegation workflow puts on every commit. Saving: the real split lets an
   audit judge whether delegation is happening, on any lane.

3. **Fix the closure scan's shared root cause once, not per package.** All
   12 GAPS packages cite the same missing `data/quality.json` and
   `onednn-qwen38-w4a16-` paths. Saving: one fix (restore or correctly
   reference those paths) likely clears gaps lab-wide instead of needing 12
   separate edits. Generalizes to any future closure-scan finding shared
   across a package family.
