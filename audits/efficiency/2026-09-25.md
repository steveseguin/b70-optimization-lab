## Top three changes

1. **Preregister LTX's packet sequence as one unattended runner, not one
   packet per manual round trip.** Evidence: packets 83-90, 50 commits in 31
   hours, 5 incident commits, each gated by its own warm/tsh/endure commit.
   Saving: this is exactly rule 4, and would likely compress a week like
   this into a shorter unattended run with the same or fewer freezes.
   Generalizes to any lane running iterative packet/arm campaigns.

2. **Make `scripts/efficiency-audit-metrics.py` flag a shallow/rewritten git
   history before trusting `campaigns_total`.** Evidence: real commits this
   window number 50, but `campaigns_total` is 421 with 0.0h median/max
   latency across n=270 pairs — artifacts of the repo's single 36,213-file
   root commit (`8c4fcb96`, confirmed as history root via
   `git rev-list --max-parents=0 HEAD`), which makes `--diff-filter=A` treat
   every pre-existing file as newly added. Saving: comparing `campaigns_total`
   against the real in-window commit count, or flagging any commit adding
   >1000 files, stops future audits from overstating throughput by an order
   of magnitude. Generalizes to any future history-recovery event, like the
   zeroed-file/zero-length-blob incidents `CURRENT.md` logs for Sept 17-18.

3. **Fix `commits_by_author`: it reports 100% "claude" while every commit's
   actual git author is "Codex Agent".** Evidence: `author_class()` overrides
   the real author whenever a commit body carries a `Co-Authored-By: Claude`
   trailer — exactly what `AGENTS.md`'s "Cross-Agent Delegation" workflow
   produces on every commit. Saving: the real split lets an audit judge
   whether delegation is actually happening, instead of always reading as
   Claude-only.
