1. **Never launch a new GPU campaign on this host after a note declares it
   corrupting data, until the memtest that note demands actually runs.**
   Evidence: packet 83 found byte-level corruption on two boots and named
   memtest86+ "ahead of every software lever"; packets 84-86 reloaded
   three more times on that unconfirmed boot (`58ae370e`, per
   `f84-tsh-04-parity.json`), leaving packet 84's "provisional" pass
   unverified. Saving: stops GPU time spent on results nobody can
   trust. Generalizes: hardware-level corruption needs a hard gate.

   endpoint commit, after unshallowing — never the audit's own branch.**
   Evidence: this run misread shallow clone `9ad6d4f2` as a squash,
   reporting 665/327/338 commits from its own branch; `38214407` gives
   660/323/337. Saving: removes a class of false metrics every future
   run would repeat. Generalizes: every run risks it.

   preg with its result, and misses `*-prereg.md` under `notes/`. Saving:
   restores per-lane throughput visibility. Generalizes: every lane here
