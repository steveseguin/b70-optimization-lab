## Top three changes

1. **Run this audit's metrics scripts against a clean checkout of the
   endpoint commit, after unshallowing — never the audit's own branch.**
   Evidence: this run's first pass misread shallow clone `9ad6d4f2` as a
   parentless squash, then reported 665/327/338 commits from its own
   contaminated branch; `38214407` direct gives 660/323/337. Saving:
   removes self-inflicted false metrics. Generalizes: every future run
   risks both unless standard.
2. **Extend the campaign glob to also match
   `experiments/*/data/*/preregistration.json`, and fix lane extraction.**
   Evidence: 11 prereg files were added this window but the top-level-only
   glob counted 4; a naive glob fix still misclassifies the rest, since
   `lane = prereg.parts[-3]` resolves to `data` for a nested path, not the
   real lane. Saving: restores real per-lane campaign counts. Generalizes:
   any subdirectory-per-campaign lane is undercounted and mis-labeled
   every week until both are fixed.
3. **Fix the closure scanner's path regex to handle brace-expansion
   instead of truncating at `{`.** Evidence: a README references a
   brace-expanded, fully tracked patch pair, but the scanner reports the
   truncated prefix as a blocking `missing_path`. Saving: removes false
   GAPS so real ones aren't lost in noise. Generalizes: any paired-patch
   credit this way hits the same false positive.
