1. **Never launch a new GPU campaign on this host after a note declares it
   corrupting data, until the memtest that note demands actually runs.**
   Evidence: packet 83 found byte-level corruption on two boots, naming
   memtest86+ "ahead of every software lever"; packets 84-86 reloaded
   three more times on that unconfirmed boot (`58ae370e`), leaving
   packet 84's "provisional" pass unverified. Saving: stops GPU time
   spent on untrustworthy results. Generalizes: hardware-level
   corruption needs a hard gate.

   endpoint commit, after unshallowing — never the audit's own branch.**
   Evidence: this run misread shallow clone `9ad6d4f2` as a squash
   (665/327/338 vs the correct 660/323/337 at `38214407`). Saving:
   removes a class of false metrics future runs would repeat.
   Generalizes: every run risks it.

   pregs; fixing that still mislabels the lane, can't pair a nested
   preg, and misses `*-prereg.md` under `notes/`. Saving: restores
