## Top three changes

1. **Run this audit's metrics scripts against a clean checkout of the
   endpoint commit, after unshallowing — never the audit's own branch.**
   Evidence: this run misread shallow clone `9ad6d4f2` as a squash, then
   reported 665/327/338 commits from its own contaminated branch; direct
   `38214407` gives 660/323/337. Saving: removes self-inflicted false
   metrics. Generalizes: every run risks both otherwise.
2. **Extend the campaign glob to also match
   `experiments/*/data/*/preregistration.json`, and fix lane extraction.**
   Evidence: 11 prereg files were added this window but the top-level-only
   glob counted 4; a naive fix still misclassifies the rest, since `lane =
   prereg.parts[-3]` resolves to `data` for a nested path, not the real
   lane. Saving: restores real per-lane counts. Generalizes: any
   subdirectory-per-campaign lane is undercounted and mis-labeled weekly.
3. **Fix the closure scanner's path regex to handle brace-expansion
   instead of truncating at `{`.** Evidence: a README references a
   brace-expanded, fully tracked patch pair, but the scanner reports the
   truncated prefix as a blocking `missing_path`. Saving: removes false
   GAPS. Generalizes: any paired-patch credit hits the same false positive.
   Caveat: only this category was spot-checked; the 12 packages'
   `host_path_hardcoded`, `missing_release_asset`, and
   `image_without_reachable_builder` findings look plausibly real and
   remain unclassified.
