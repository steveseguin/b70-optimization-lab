## Top three changes

1. **Unshallow (or verify clone depth) before every scheduled audit.** Evidence:
   this clone was shallow; `campaigns_total` was 421 at 0h/0h latency,
   misattributed to the boundary commit, vs. 4/n=0 post-unshallow. Saving:
   stops future reports publishing fabricated numbers. Generalizes to any
   lane, any fresh checkout.
2. **Widen the campaign glob** to also match nested
   `experiments/*/data/*/preregistration.json`, **and** fix lane extraction
   with it: `lane = prereg.parts[-3]` resolves to `data` (wrong) for that
   layout — widening alone would mislabel every nested campaign. Derive lane
   from the path segment after `experiments/`. Evidence: `git log
   --diff-filter=A` shows 7+ preregistrations under that layout the glob
   misses. Saving: correct visibility, not a mislabeled undercount.
   Generalizes to every such lane.
3. **Teach `public-closure-scanner.py` to recognize docker-env-only paths and
   overridable Dockerfile `ARG` defaults before treating output as a gate.**
   Evidence: both GAPS flags on `qwen38-27b-fp8-vllm-tp1-b70` are false
   positives (above). Saving: gating publication on it as-is would block
   reproducible packages; the other 10 GAPS candidates need the same patterns
   ruled out first. Generalizes to any package with an in-container env path
   or overridable `ARG`.
