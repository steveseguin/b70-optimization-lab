(LTX graph capture, Qwen3.8 27B one-card FP8) after real determinism debugging,

## Top three changes

1. **Unshallow (or verify depth of) the clone before every scheduled audit.**
   Evidence: this session's clone was shallow; `campaigns_total` was 421 with
   0h/0h latency, all misattributed to the 2026-09-14 23:26:14 boundary commit,
   versus 4 campaigns / n=0 after `git fetch --unshallow`. Expected saving:
   stops every future weekly report from publishing fabricated throughput and
   latency numbers. Generalizes to any lane, any week, any fresh checkout.
2. **Widen `efficiency-audit-metrics.py`'s campaign glob** from
   `experiments/*/data/*prereg*.json` to also match nested
   `experiments/*/data/*/preregistration.json`, **and** fix lane extraction with
   it: the script derives `lane = prereg.parts[-3]`, correct for a flat
   `experiments/ltx25-b70/data/stability-01-prereg.json` but `data` (wrong) for a
   nested `experiments/ltx25-b70/data/<campaign>/preregistration.json` — widening
   the glob alone would silently mislabel every nested campaign's lane. Derive
   lane from the path segment right after `experiments/` instead. Evidence:
   `git log --diff-filter=A` in-window shows 7+ preregistrations under the
   nested layout the current glob misses entirely. Expected saving: correct
   per-lane visibility instead of trading an undercount for mislabeled counts.
   Generalizes to every lane using that layout (ltx25-b70, newer qwen38-27b-b70).
3. **Add `tools/public-closure-scanner.py` to the documented publication
   checklist** in AGENTS.md's "Publication surface for this lane" list, which
   names `check-doc-links.py`, `check-manifest-paths.py`, and
   `check-pinned-hashes.py` but not the closure scanner. Evidence: this week's
   own `qwen38-27b-fp8-vllm-tp1-b70` publish scans GAPS (see above), which none
   of the existing three checks catch. Expected saving: catches portability/
   closure defects before publish instead of in a follow-up cycle. Generalizes
   to every future package publication in any lane.
