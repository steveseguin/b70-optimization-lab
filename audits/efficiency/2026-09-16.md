# Efficiency audit — 2026-09-16

## Verdict

Two exact speedups landed this week (LTX graph capture, Qwen3.8 27B one-card
FP8) after real determinism debugging — but neither is a confirmed *speed* win
by AGENTS.md's two-fresh-servers rule: LTX is single-server throughout, and even
the accepted qwen38 depth-6 number is a single run (Rule compliance). The audit's

boundary commit. After `git fetch --unshallow` (read-only), the real picture is
729 commits and 4 campaigns detected — itself an undercount (below). Wall-clock
mostly went to GPU faults and negative screens, not the two wins.

## Where the week went

`qwen38-27b-fp8-vllm-tp1-b70` scans GAPS, but both flags are scanner defects: the
flagged `serve.py:24` path is a docker-env value baked into the image, and the
flagged Dockerfile `ARG BASE=...` is documented as overridable. See change #3.

**qwen38-27b-b70 (two-B70 host):** three GPU faults each halted work and needed a
live user decision — 09-14 18:30, 09-15 02:20, and 09-16 06:02 (still open).

communicator, both speed-neutral or not worth adopting, before the GDN-prefill

**ltx25-b70 (four-B70 host):** a long chain of exact-but-slower or CPU-only

single-server (Rule compliance) — then packet22's decoder extension caused a CAT

## Top three changes

1. **Unshallow (or verify clone depth) before every scheduled audit.** Evidence:
   this clone was shallow; `campaigns_total` was 421 with 0h/0h latency, all
   misattributed to the boundary commit, versus 4 / n=0 after
   `git fetch --unshallow`. Saving: stops future reports from publishing
   fabricated throughput/latency. Generalizes to any lane, any fresh checkout.
2. **Widen `efficiency-audit-metrics.py`'s campaign glob** to also match nested
   `experiments/*/data/*/preregistration.json`, **and** fix lane extraction with
   it: `lane = prereg.parts[-3]` resolves to `data` (wrong) for that layout, not
   the lane name — widening the glob alone would silently mislabel every nested
   campaign. Derive lane from the path segment after `experiments/` instead.
   Evidence: `git log --diff-filter=A` in-window shows 7+ preregistrations under
   the nested layout the glob misses. Saving: correct per-lane visibility
   instead of an undercount traded for mislabeled counts. Generalizes to every
   lane using that layout.
3. **Teach `public-closure-scanner.py` to recognize docker-env-only paths and
   overridable Dockerfile `ARG` defaults before treating output as a gate.**
   Evidence: both GAPS flags on `qwen38-27b-fp8-vllm-tp1-b70` are false
   positives — an env-baked docker path and an overridable `ARG BASE=...`.
   Saving: without this, gating publication on the scanner would block
   reproducible packages; the other 11 GAPS packages need the same two patterns
   ruled out first. Generalizes to any package with an in-container env path or
   overridable base-image `ARG`.
