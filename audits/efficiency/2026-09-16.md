## Top three changes

1. **Unshallow (or verify clone depth) before every scheduled audit.**
   Evidence: this clone was shallow; `campaigns_total` was 421 at 0h/0h
   latency, misattributed to the boundary commit, vs. 4/n=0 post-unshallow.
   Saving: stops fabricated numbers. Generalizes to any lane, any checkout.
2. **Widen the campaign glob** to also match nested
   `experiments/*/data/*/preregistration.json`, **and** fix lane extraction
   with it: `lane = prereg.parts[-3]` resolves to `data` (wrong) for that
   layout — widening alone would mislabel every nested campaign. Derive lane
   from the path segment after `experiments/`. Evidence: `git log
   --diff-filter=A` shows 7+ preregistrations under that layout the glob
   misses. Saving: correct visibility, not a mislabeled undercount.
   Generalizes to every such lane.
3. **Fix `public-closure-scanner.py`'s false positives:** docker-env paths and
   overridable `ARG`s aren't host-path gaps, and a failed `gh` lookup should
   be "unknown," not "missing" (above). Saving: gating publication on it
   as-is would block reproducible packages behind noise.
