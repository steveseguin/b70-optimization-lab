## Top three changes

1. **Enforce rule 8 mechanically, not by memory.** A preflight lock refusing a lane launch while another lane's
   container/launcher is active on the same host. Evidence: the A61 lockup cost a full reboot and produced the rule as
   a manual fix the same day it was needed. Expected saving: one host-reboot cycle (~1+ hour) per future collision.
   Generalizes to every future lane pair sharing either host.
2. **Extend rule 5's fast-fail to silent freezes.** Add a startup liveness check (no worker log line for N seconds)
   alongside the fixed fault-signature grep. Evidence: ≥7 Flash-Next host freezes this week, several undetected by
   signature matching (CURRENT.md, 09-04/09-05). Expected saving: the health-timeout wait rule 5 exists to eliminate,
   for hangs without a logged fault. Generalizes to any lane whose failure mode is a wedge.
3. **Require a mechanism-component census past ~10 arms without a gate pass.** Write down which layer
   (scheduler/kernel/sampler) each next arm targets before running it, mirroring rule 1 for non-batch-shape bugs.
   Evidence: R170-R174 excluded four hypotheses serially before the real one. Expected saving: a chunk of the ~1.5-day
   chase; most future lanes will hit multi-arm correctness hunts too.
