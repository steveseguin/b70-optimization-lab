## Top three changes

1. **Merge or close the six backlogged audit PRs before opening the next one.**
   Evidence: #51–#56 are all `mergeable_state: clean`, reviewed only by the automated
   Codex bot and the author, none approved (verified via `pull_request_read`).
   Saving: stops the same bugs (this metrics-glob bug, the shallow-clone default)
   being rediscovered every day instead of fixed once. Generalizes to every future
   week — the audit only compounds the lab's speed if its own output lands.
2. **Add `watchdog:.*hard LOCKUP` to the shared GPU-fault regex.**
   Evidence: `experiments/ltx25-b70/scripts/kernel_fault_detector.py:9`,
   confirmed unpatched; the miss is documented in the lab's own note. Saving:
   faster detection the next time this fault class recurs on any lane sharing
   the launcher. Generalizes to every lane using this detector.
3. **Make `scripts/efficiency-audit-metrics.py`'s prereg glob recursive.**
   Evidence: `experiments/*/data/*prereg*.json` (line 107) misses 7 of 428
   on-disk preregs that live in per-campaign subdirectories, confirmed by
   diffing the flat glob against a recursive one. Saving: restores real
   throughput/latency numbers so this report (and every future one) can
   measure the whole lab instead of one lane. Generalizes to every lane using
   the subdirectory layout.
