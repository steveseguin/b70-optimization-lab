# Qwen 27B exact-depth fixtures

These grade-C fixtures provide one deterministic flat token-ID input at each
declared active-context depth:

`0, 2048, 4096, 8192, 16384, 24576, 32768`.

They were generated by `scripts/build-qwen27-exact-depth-fixtures.py` from the
tracked 25-prompt validation suite. Source token IDs are repeated and truncated
to the exact requested count. This makes the input cardinality reproducible;
it does not claim that repeated synthetic context is representative of natural
long-context quality.

The Qwen3.6, Qwen3.8 27B, and Qwen3.8 Flash-Next tokenizer files have different
byte identities, so the fixtures retain separate revision-specific provenance.
For this frozen corpus, however, every one of the seven prompt-token hashes is
identical across all three fixtures. The same exact workload can therefore
compare the weight families without treating their artifacts or evidence as
interchangeable.

  `85b1050c88b4c1e6cb9c4ce7f1580284cd2aa68243dad0d0dff16460decbe5ac`;
- `qwen38-bce40ca-exact-depth-v1.json`:
  `ebe507b725af6ec0713de4084d0bf52fbbab48b151511e0019c1bac2c5051bd9`;
- `qwen38-flash-next-bcd9f01-exact-depth-v1.json`:
  `c44fccbaf600cc506d8ed0cc7357161057b86abc44469b611be71db97558061d`.

Depth zero is intentionally an empty token array. It is valid for lower-level
engine or `llama-bench` capability work only; the OpenAI-compatible benchmark
client refuses to substitute a one-token request for it. A measured D>0 cell
must still prove exact prompt usage, cache zero, sufficient configured
capacity, no truncation/context shift, 128 returned IDs, and the conventional
100-event/99-interval timing window.

## Mixed real-content fixture

`qwen38-bce40ca-mixed-content-depth-v1.json` is a separate Grade-B context
fixture. It contains three cases at each nonzero canonical depth: unrepeated
prefixes of repository-tracked technical prose, Python code, and structured
documentation. It was generated by
`scripts/build-qwen27-mixed-content-depth-fixture.py`; source paths are relative
to this repository, and the fixture binds every source, tokenizer file, and
generator by SHA-256. Its artifact SHA-256 is
`a8a48b3549062759cc94b28f2360bea119f8adde582ace04928111b624d952ed`.

This is representative real-content context-shape evidence, not a natural
retrieval/task prompt suite. Each published depth must aggregate the three
classes and independently pass the same cache, truncation, token-identity, and
target-oracle gates. No point may be inferred from the older repeated-token
fixture or from another depth.
