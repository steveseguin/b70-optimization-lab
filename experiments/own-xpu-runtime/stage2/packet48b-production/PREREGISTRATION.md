payload is used. Physical card 0 only, with normal coordinator ownership,
health, memory and storage admission. This is a synthetic operator screen,
never a model throughput or quality headline.

production submission. Its expert controls were the production P39 kernels;
their surrounding workload and generated values differed from packet46.
Do not waive its failed 15% control check or relabel its 52 microsecond sum as
a production saving.

This packet derives the complete layer harness from packet46. The current
arm calls packet45's actual `Engine::execute_site`, using the same sealed
dispatch, ordinary GDN layer 4 and QSA layer 3, full row sizes, quantizations,
32-block deterministic synthetic fixture generator, 4K occupied context,
10 warmup pairs and 200 measured pairs. It is M=1 only. No launch fusion.

checked compact layout and exact-order lane functions. The adapter preserves
SG32 ownership, lane product/add order, adjacent reduction, BF16 store, route
status and sticky errors. Repacking occurs outside the measurement and rejects
nonfinite scales. Both banks exist only in this small comparison fixture.
An engine integration must replace allocations and prove its per-card reserve.

The current and candidate execute from identical saved state. E1 and E2 are
fresh processes covering the existing six context/control cases per layer.
Every producer output and all mutable allocation bytes must match. Fresh
complete comparison identities must match. The two CPU-only fixture processes
exercise that same layer composition before sealing; they do not pass device
gates. Packet48 already supplies isolated special-value/route byte tests;
this packet adds actual layer composition, rather than replacing those tests.

T1 and T2 are separate fresh processes, bound to both exactness windows and
the same seal, binary, boot, environment and reviewed-fault boundary. Restore
identical state and alternate arm order. Sum each completed compute event once;
report every class and the complete layer. Both arms must retain the exact
35/41 physical launch counts. Compare full mutable bytes for all 420 timing
pairs as well. Do not count copies/repacking or compare unlike timestamp epochs.

per complete layer** in both owners. Report per-class paired savings. A class

3 microseconds and 5% on that class. These rules are fixed before device work;
