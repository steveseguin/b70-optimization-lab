# Packet45 artifact retention

This packet intentionally retains evidence larger than 1 MiB. Size alone is not
a reason to delete a failed run. The full file inventory and hashes are in
`merge-inventory.json`; final accepted receipts are bound by `build-receipt.json`.

| Artifact | Why retained | Reproduction or restoration |
|---|---|---|
| `merge-inventory.json` | Complete per-file comparison against both immutable parents, including omitted historical evidence and current file hashes. | Run `merge_inventory.py` after final artifacts are written. |
| `rope.bf16` (4 MiB) | Frozen host-generated RoPE arithmetic is part of identity v2; regenerating with another math library could change output. | Copied byte-for-byte from the pinned packet44 parent; hash is in the source seal. |
| `evidence/draft-baseline-rows.jsonl.gz` (5.84 MB) | Exact historical draft reference bytes, not an inherited pass. | `draft_baseline.py --prepare` rebuilds the compressed reference from the pinned baseline; the oracle receipt lists input/member hashes. |
| `cpu-merged-gates.json` | Final per-case token, layer, complete target-state and draft-state hashes, comparisons and archive bindings. | Run `cpu_merged_gate.py` with the sealed GNU host binary. |
| `cpu-merged-first.json`, `cpu-merged-before-hc.json` | Earlier completed CPU campaigns retain the identities that were actually tested; neither qualifies final changed sources. | Their source pins and corresponding compressed scratch archives preserve the evidence. Exact historical runtime reconstruction requires those recorded source versions. |
| `cpu-merged-interrupted-source-change.json` | Preserves the interrupted prefix and its explicitly failed completion status. | Inspect the retained rows and compressed events. Do not report the prefix as a completed campaign. |
| `capacity-fixture-gates.json` | Preserves failed integration attempts and the complete final compiler/capacity matrix, including exact source and fixture identities. | Run `capacity_fixture_gate.py`; historical failing rows remain evidence rather than being overwritten. |
| `evidence/scratch-merged-gate-1791904050083284456-real-*.jsonl.gz` (six archives) | Exact text/events plus hashes of all disposable binary state for the six real-model checks; each archive is about 1.3 MB. | Verify with `storage.verify_archive`; recreate binary fixtures using `cpu_real_gate.py` and the sealed local model/input identity. |
| `cpu-real-gates.json`, if above 1 MiB | Six real-model correctness subsets with per-layer hashes and oracle bindings. | Run `cpu_real_gate.py` against the local approved model/input files; it is not a speed test. |

Scratch archives use `packet38.scratch-stream.v1` JSONL in gzip. `storage.py`
streams and verifies each retained member's byte count and SHA256 before deleting
its scratch directory. Text, JSON, events, traces and nested gzip members are
retained exactly as base64 chunks; large disposable binary model fixtures retain
their original hashes and are regenerated by the corresponding gate. Read the
member's `retained` field: a hash-only entry does not claim its bytes were saved.
`storage.verify_archive(path)` verifies the exact archived members without
recreating multi-gigabyte scratch. Fixture gates additionally retain their
compressed golden output blobs. Draft captures preserve only valid frozen
reference files; no raw CPU fixture directory is left in the ignored build tree.

`evidence/build-object-retirement.json.gz` inventories compiler object hashes
removed after every linked artifact matched its mode build receipt. Binaries,
compile commands, link commands and source files remain. Rebuild the object files
with the documented compiler modes and at most two jobs. The ignored build tree
must stay below 3 GB; this retirement made room for maximum-context CPU fixtures.

`dense-fourparts-device-failure.jsonl.gz` preserves the original failure
record byte-for-byte. Its retention receipt binds compressed and uncompressed
hashes. It is historical card evidence supplied by packet42, not a device run by
this CPU-only task.

Every producer checks `df -B1 /` before a large write and refuses when the planned
write would leave less than 8 GB free. No weights, build binaries or model caches
are committed. The parent packet trees and unrelated workspace artifacts are
preserved.


The October 13 HC repair retains `evidence/hc-activation-fix/`: the six negative
and six passing compiler logs, source-bound gate receipts, hashes of the original
device failure inputs and binaries, and a verified archive of the prior CPU seal
receipts. `prior-seal-retention.json` identifies that archive; Markdown members
are hash-only there and retain their bytes in Git at `7b0ec5bb5`.

The new `scratch-merged-gate-*-real-*.jsonl.gz` archives may again exceed 1 MiB.
They retain exact request/events/receipt text and original disposable fixture
hashes for the repaired runtime, and are bound by `cpu-real-gates.json`.
Regenerate them with `hc_fix_campaign.py models`, using the pinned local inputs.
New capacity fixture records and output archives preserve the same source,
compiler, capacity and output binding as the earlier rows. Do not remove old
rows or conflate their binaries with the repaired ones.

`cleanup-*-objects.json` in the repair evidence folder records each mode's
regenerable object retirement. The linked artifacts and build commands remain;
`hc_fix_campaign.py builds` rebuilds them with at most two compiler jobs.
The coordinator's original `build/FAULT.json` and failed K1a directories are
excluded from all cleanup and remain byte-identical to `protected-inputs.json`.

`original-device-failures.jsonl.gz` retains exact copies of the coordinator's
nine failure-evidence files (base64 members, individually hashed), including the
latch. Its retention receipt records verified restoration. The original files
and both partial binary outputs remain untouched; all 13 protected input hashes
were checked against the initial snapshot.
