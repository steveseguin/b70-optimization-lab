# Bounded interactive owner — CPU preparation

Packet200 composes the unchanged p198 model binary with the frozen bounded
profile/session and diagnostic drainer. No device window is queued or launched.
The command-line interface is read-only `--plan`; operational execution is a
separate coordinator function gated by a future root-owned manifest.

The proposed session accepts at most sixteen sequential local chat requests,
context4096 and full BF16 state. Its768MiB storage forecast is monitored, not a
hard quota. The27GB root floor and frozen profile's false readiness flags remain
unchanged. Checkpoints use512MiB parking with256MiB SAVE reservations.

One explicit owner and resource ledger retains uncertain processes, pipe
endpoints and threads. No automatic restart, retry, resource-limit adjustment,
forced kill or checkpoint cleanup is provided. See the final CPU test receipt
when available; synthetic tests are not native or device qualification.
