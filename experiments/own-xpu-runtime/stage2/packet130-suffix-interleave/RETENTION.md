# Retention and rebuild

The committed source copy and parent manifest preserve the immutable inputs.
Directory/file symlinks are copied as symlinks; `oracle` remains the packet49
identity link. Historical parent builds, chain outputs, seals and device
receipts are not cloned into this packet. The small fusion-header build link
is reconstructed from the copy manifest before mirroring sources.

Build directories are ignored. Recreate them with the README's serial CPU
commands. The build receipts bind the exact inherited arithmetic objects in
packet124c's local build and its pinned source closure. These are local lab
reproduction dependencies, not a publicly published recipe.

Keep compressed full-vocabulary head bytes, controller verdicts, exact source
and binary hashes, verified full-shape startup archives, negative drain log,
argument/queue/limit receipts and future device receipts. Full-size synthetic
weight arrays are generated in memory. Reset-state scratch is removed only by
its original-byte retention gate. No frozen experiment artifact is deleted.
