# Packet193 retention

Tracked: sources (`micro.cpp`, `p193_diet.hpp`, the Python gates incl. `isa_count.py`), the private include closure
`native-pinned/` (46 files copied from packet192's pinned copy; provenance in `native-provenance.json`), `lineage-inputs/`
(the 384-route JSON, identical to packet192's derivation, and the parent provenance records), `proposals/`,
`report-contract.json`, the evidence receipts (`build.json`, `isa.json` + `isa/*.asm.gz` (6 kernels, ~0.3 MB) +
`isa-rejected/` (the two rejected forms), `fixtures.json`, `cpu-rehearsal.json`, `admission.json`, `cpu-seal.json`,
`package-rows.json`, `check-queue-rows.json`, `pin-guard.json`, `plan-B.json`, `entry-report.json`, `final-checks.json`,
`final-pin-guard.json`, the two CPU host streams (~1.3 MB each), `do-not-repeat-search.txt`, the analyzer test log) and
`READY-FOR-DEVICE.json`.

Ignored (`.gitignore`): `build/` (three binaries ~0.9 MB; the 31 MB exactness fixtures under `build/fixtures/`; the offline
ISA pipeline intermediates under `build/isa/` ~20 MB; dependency lists; logs). Fixtures are regenerated byte for byte by
`rehearse_cpu.py` (GNU writes, Intel verifies); their digests are sealed in `evidence/fixtures.json`.

Parent inputs are read in place, never copied: `packet100b-route-capture/evidence/routes.bin` + `route-inputs.json`,
`packet162-iq2-lookup/build/micro-inputs/layer{0,24}.bin` (2 x 10,496,000 B of real GGUF rows), packet192's
`issue-floor-B1/analysis.json` + `samples.jsonl` (control datums; the stream is refused by the analyzer), packet110's
`roofline.json`. Every `run_micro.py --plan/--run` re-hashes them against `lineage-inputs/parent-inputs.json`.

Device output: `evidence/diet-B1/` (must not exist before the window): `samples.jsonl` (about 25 MB; 96 MiB reserved),
`window.json`, `analysis.json`, `s193_report.md`, kernel journals, `native-home/` (ignored). The report appends one
measured row per candidate to `DO-NOT-REPEAT.md`. No retry: a failed window keeps its directory for review and the packet
is not resealed.

Disk at preparation: root free 29 GB throughout (floor 27 GB for CPU work, 25 GB shared device floor); build tree 55 MB
(cap 2 GB). Nothing was deleted to make room.
