# Packet157 retention

The vendored source closure and report fixture are required to reproduce CPU
entry, report and native builds without mutable parent dependencies. Some
inherited JSON fixtures exceed 1 MiB; they are retained as regression inputs,
not packet157 measurements. Restore them from this packet's Git commit.
The report inputs were reduced to the fields consumed by the report gate;
the complete copied inputs remain recoverable from milestone `de65d4237`.
This removes stale nested parent paths from the active dependency graph.
The report gate passes with these explicit subsets. Intermediate entry object
files are regenerated by the build script; final launch binaries are retained.

The build binaries and immutable input objects are retained in this packet,
following the parent packet convention. They are needed for this incremental
build and byte-specific launch seal; they can be restored from this packet's Git commit. Immutable originals are hash-bound
in immutable-binaries.json and the original packet136 build recipe is retained
under lineage-inputs/packet136-history. Rebuild from the vendored sources and
record new hashes when intentionally rebuilding the immutable objects; never silently
substitute an unverified object. Packet157's device evidence is still pending.
