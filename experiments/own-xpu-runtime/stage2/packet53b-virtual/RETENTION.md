# Retention and rebuild

Only this packet's build tree and device evidence are ignored. Retain final
binaries and checked source mirrors under build/, bounded below500 MB.
CPU receipts, logs and compressed native assembly are tracked. No model
weights or protected chain/oracle files are copied or cleaned.

Initial register investigations remain under evidence-cpu/initial-grf128,
grf-property-refusal, blocked-chain-spills, scalar-decode-spills and
split-stream-screen. Original receipts preserve their original bytes and
artifact paths. In each archive, `registers/` is the relocated original
`evidence-cpu/registers/`; resolve those historical artifact paths there.
The initial include/mirror errors are compiler refusals, not GPU incidents.
The exact rejected header and assembly identify each scheduling experiment.

All offline bitcode, SPIR-V, IGC dump duplicates and compiler objects are
regenerable. Cleanup inventories list original sizes and hashes before
removing this packet's own scratch. Compressed assembly and compiler logs
remain, along with the source and tool hashes needed to rebuild. Final
register evidence uses the final checked device source mirror and device
build receipt. Its source manifest is verified again before sealing.

See CPU-BUILD.md for serial regeneration. Old rejected scheduling attempts
must be rebuilt in a new scratch directory using their retained header;
never overwrite a qualified sealed packet to reproduce a failed experiment.
