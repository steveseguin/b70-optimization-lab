# Retention

This packet intentionally copies packet118's source bundle and pinned lineage
inputs. `copy-lineage.json` records the parent commit and original hashes.
Existing source trees and measured outputs stay frozen. Copied prior root
receipts that are not regenerated by this packet are historical, not admission.
The active screen seals live only under `selections/`.

The 4 MiB rope table, approximately 0.76 MB MTP metadata, source snapshots and
copied lineage metadata are necessary for reproducible real-shape initialization,
compiled source closure and exact byte fixtures. They are retained even where
they duplicate an ancestor. No model payload weights are copied. New build
binaries/objects stay ignored; compile commands and source hashes are recorded.
Inherited compiled objects refer only to the frozen ancestor source closure and
are content-checked before linking; no mutable parent selection or orchestration
result authorizes the packet. Never rebuild through a selection's hardlink.

`evidence/generated-cpu-evidence.tar.gz` retains generated source and small CPU
receipts with a per-member hash manifest. It is checked byte-for-byte before
use; `restore_links.py` restores missing build evidence. No existing artifact is
removed. Full census lists are deterministically compressed, with separate
allocator and driver-pool semantics. CPU fixture refusals are retained.

Large tracked members are intentional:

| File | Bytes | Retention and restoration |
| --- | ---: | --- |
| `rope.bf16` | 4,194,304 | Real-shape rotary fixture; restore the exact parent bytes recorded by `copy-lineage.json`. |
| `lineage-inputs/fusion-rope.hpp` | 12,582,900 | Generated C++ rotary constants used by both compiler byte gates; retained verbatim from the pinned copy, not regenerated with different rounding. |
| `lineage-inputs/packet103-composition-selection.json` | 1,993,365 | Frozen composition and transitive source identity; restore the copy-lineage-pinned parent artifact. It does not authorize a current parent output. |
| `evidence/generated-cpu-evidence.tar.gz` | 4,125,590 | 260 generated source/CPU receipt files; `build-retention.json` binds every member, and `restore_links.py` verifies and restores missing build evidence. |

Selection binaries are ignored hardlinks to this packet's build; they add no
new binary payload and are recreated by `prepare_packet.py` after the build.
