# Integration boundaries

Packet32 is the common base. Packet37 contributes the prepared command owner,
argument serialization, fixed K2 fusion selection and packet33 kernels. Packet36
contributes the official draft preparation, authentication, captures, provider,
controller interface and draft receipts. The three-way source inventory is in
merge-inventory.json; source-overlay.json records the final local overlay.

The draft issues captured commands through the same prepared owner as its
target. It does not release scratch independently. All target and draft mutable
allocations are zeroed in place between suite requests; immutable allocation IDs
and captured bindings survive. The explicit negative lifetime gate proves that
releasing even an unrelated allocation invalidates target captures, and the
positive gate proves in-place reset keeps them usable.

Packet30 attention variants and small rows4 are candidates, not automatically
promoted winners. K2 must time the actual decode contexts and capacity before
choosing them. Packet39 epilogues remain disabled. This packet never applies a
packet39 patch or changes its files.

CPU qualification is source- and binary-bound in build-receipt.json. CPU timing
is controller/host diagnostic evidence only. All device windows remain mandatory;
none ran during preparation. No parent packet, oracle, host setting or scoreboard
is changed.
