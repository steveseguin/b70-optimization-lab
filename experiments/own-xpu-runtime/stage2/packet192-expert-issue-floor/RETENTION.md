# Packet192 retention

Tracked: sources (`micro.cpp`, `p192_noload.hpp`, the Python gates), the private include closure
`native-pinned/` (46 files, 444 KB; provenance in `native-provenance.json`), `lineage-inputs/`
(the 384-route JSON derived from packet100b and the parent provenance records), `proposals/`,
`report-contract.json`, the evidence receipts (`build.json`, `fixtures.json`, `cpu-rehearsal.json`,
`admission.json`, `cpu-seal.json`, `package-rows.json`, `check-queue-rows.json`, `pin-guard.json`,
`plan-B.json`, `entry-report.json`, `final-checks.json`, `final-pin-guard.json`, the two CPU host
streams and the analyzer test log) and `READY-FOR-DEVICE.json`.

Ignored (`.gitignore`): `build/` (three binaries, 0.65 MB; the 29.6 MB exactness fixtures under
`build/fixtures/`; dependency lists; logs). The fixtures are regenerated byte-for-byte by
`rehearse_cpu.py` (GNU host twin writes, Intel host twin verifies); their digests are sealed in
`evidence/fixtures.json`, so a lost `build/` is a rebuild, never a loss of evidence.

Parent inputs are read in place and are never copied: `packet100b-route-capture/evidence/routes.bin`
(46,080 B) and `route-inputs.json`, `packet162-iq2-lookup/build/micro-inputs/layer{0,24}.bin`
(2 x 10,496,000 B of real GGUF rows), packet100b's micro-B window/samples/qualification, packet162b's
device analysis, packet110's `roofline.json`. Every run of `run_micro.py --plan/--run` re-hashes
them against `lineage-inputs/parent-inputs.json`. Keep those parents; this packet does not duplicate
them (brief rule: no run/ copies into lineage-inputs; pin read-in-place by sha256).

Device output: `evidence/issue-floor-B1/` (must not exist before the window): `samples.jsonl`
(about 8 MB, 64 MiB reserved), `window.json`, `analysis.json`, `s192_report.md`, kernel journals,
`native-home/` (ignored). The report appends one measured row to `DO-NOT-REPEAT.md`. No retry: a
failed window keeps its directory for review and the packet is not resealed.

Disk at preparation: root free 29 GB before, build tree 30.3 MB; the CPU floor is 27 GB, the device
floor the shared 25 GB. Nothing was deleted to make room.
