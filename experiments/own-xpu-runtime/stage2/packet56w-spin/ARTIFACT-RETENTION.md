# Generated CPU fixture dependency

The sealed compiler closure inherits one generated file outside Git:
`experiments/own-xpu-runtime/stage2/packet45-merged3/build/fusion-rope.hpp`.
The parent build already contains it. It is 12,582,900 bytes of decimal
`uint16_t` constants, exactly generated from the retained 4,194,304-byte
`rope.bf16`. The latter is a tracked, read-only link to packet56's tracked
fixture. Neither parent file was modified.

`prepare_cpu_input.py` derives the complete header in memory and verifies its
SHA256 against the existing screen seal. On this host it restores only the
candidate's read-only `build/fusion-rope.hpp` link. On a fresh checkout without
the inherited header it writes the identical generated bytes into this
candidate's build directory instead. The rebuild then binds that local path
in its new build receipt. The compiler code and fixture bytes do not change.
Do not overwrite a screened candidate's seal when reproducing; use a new
candidate packet folder on main.

This generated header is not committed as a duplicate 12 MB artifact. Its
source, exact generation code, hash-bound identity and
[derivation receipt](evidence/rope-input.json) provide restoration. Device
binaries remain ignored local build artifacts and are rebuilt from the
recorded compiler commands. The original CPU/screen seals remain unchanged.
