# Packet51 evidence retention

`exact-capture-manifest.json` is a 1,287,927-byte required gate input. It records
all 5,472 producer/final capture identities for 36 cases. Keep it uncompressed:
the sealed coordinator reads it directly to reject missing or changed captures.
It can be regenerated by `cpu_layer_gate.py` with the pinned host executable;
its SHA256 is in `cpu-layer-gates.json` and `seal.json`.

`evidence-cpu/successful-layer.tar.gz` preserves both passing full-layer raw
receipts, comparison streams, native manifests and logs. Each member was
compared byte-for-byte with its retained original. The archive/member hashes
are in `evidence-cpu/successful-layer-archive.json`. Originals remain under the
ignored `evidence/` directory; no evidence was removed to make this archive.
Restore from the packet directory with:

```bash
tar -xzf evidence-cpu/successful-layer.tar.gz
```

Build binaries, source mirrors, relink proofs and compiler logs stay local and
are bound by build/gate receipts. Rebuild serially using README commands with
the pinned compiler and verified packet45 object closure. `cleanup.py` removes
only packet51 CMake objects/dependency files and records their hashes and
restore instructions; it never removes other packets or measured evidence.
Earlier failed source snapshots and receipts remain in `evidence-cpu/`.
