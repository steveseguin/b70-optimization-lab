# Packet 21 CPU-only campaign

The host remains in FAULT HALT. No device binary, discovery call, GPU file,
parked process, sudo, power, or memory setting is used. Only packet21 is writable.

Start with committed packet18 (source SHA256 manifest) and immutable v2 oracle.
Frozen on: 64 tokens and 384 BF16 layer fixtures; R5 on: eight tokens and
384 fixtures. All comparisons are byte equality. Integration: both card counts,
three response lengths, fresh repeats, rejection cases; fusion off is compared
with the original packet18 CPU executable and identical fixtures.

The randomized dependency checker covers both owner counts, seeds 0/1/17/73,
mini and real resident position zero plus generated inputs; full 87-position
first-token run once. Unknown access contracts fail closed. ASan/UBSan guard
checks cover invalid indices separately. No CPU gate loads a device library.

Fixture executables: GNU and Intel host builds, two fresh processes each,
all matrix classes, M=1/3/87, odd rows and mixed-class boundaries, prologues,
paired epilogues, route indexing and alias rejection. Compile/link SYCL only;
assert precision flags in generated commands and recursively grep device math.

Count actual CPU compute submissions. Frozen off split4 must execute two
operations, not label one operation as two. Per-layer census uses an additional
short real execution with site logging; it is a launch census, not a benchmark.

No device speed is claimed. K1/W0/W1/W2/W3 remain separately admitted after
reboot, with bound sources, inputs, receipts and roomy watchdogs.

First full CPU attempt was stopped cooperatively before fixtures because its
host emulation redundantly recomputed the same HC input for every GEMV row.
The retained failed receipt is not correctness evidence. The host now evaluates
that pure expression once per descriptor input row within each submission;
there is no reuse between submissions, tokens or requests. Device expressions
are unchanged. All gates run fresh on the revised host binary.

The second CPU attempt was also stopped cooperatively before completion so
all final gates bind the added malformed-peer descriptor guard. It is retained
as an interrupted attempt, not a mismatch or a passing result. The final runtime
sources were frozen before the complete runs.
