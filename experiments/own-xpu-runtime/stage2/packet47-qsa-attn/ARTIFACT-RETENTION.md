# Packet47 retained CPU evidence

The four `evidence/cpu-*/{gnu,intel}-{1,2}.raw.gz` files are about 1.4 MiB each.
They are intentionally above the repository's 1 MiB review threshold. They
retain all historical and split BF16 outputs and the new binary32 pre-gate
outputs from four separate native CPU processes, with two compilers. This
allows independent byte-level inspection of the arithmetic rebase and fresh
process reproducibility without model weights or the originating machine.

`cpu-gates.json` records every compressed-file SHA256, uncompressed SHA256,
length, source closure, compiler identity and per-process command. The runner
verifies decompression reproduces the exact original bytes before deleting
only the temporary uncompressed `.raw` file that it created. No prior evidence
is removed. The JSONL cases define the concatenation order; `ORACLE.md` defines
the byte layout. A failed process keeps its original partial files.

These outputs can be regenerated by the two CPU commands in `ORACLE.md` using
the exact pinned source/compiler identities. A new run uses a new timestamped
directory and never overwrites prior evidence. The authoritative stored bytes
remain the committed gzip files; a future compiler's agreement is not assumed.

The approximately 150 KiB host test executables and the device binary are
ignored build products. Source, build commands, compiler versions and binary
hashes remain in `build-host.json` and `build-device.json`. No weights, copied
runtime tree or intermediate compiler object collection is retained here.
