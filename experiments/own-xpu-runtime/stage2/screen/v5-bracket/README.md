# Packet 98: one-load screen brackets (v5)

CPU preparation in progress. No device execution is authorized by this packet.
V4 and every existing packet remain unchanged. This directory starts as a copy
of v4; `v4-copy-provenance.json` pins that source.

The bracket holds one lane lease and one rank pair, loads target and draft once,
and runs incident64 plus all twelve cold 128-token requests in each view.
The first proposed use is two identical packet84 production selections on B.
Only after that passes may the five-view packet91 control/candidate/control/
candidate/control bracket run. Device identity and wall-time savings are pending.

Only storage-preserving selection changes are admitted. Head transpose, packed
layout changes, draft changes, placement changes and dispatch changes require a
fresh load. Kernel capture is rebuilt at a quiescent boundary. Every view must
pass total state reset, loaded arena identity, and the packet49 exact oracle.
These are diagnostic screens, never record or promotion evidence.
