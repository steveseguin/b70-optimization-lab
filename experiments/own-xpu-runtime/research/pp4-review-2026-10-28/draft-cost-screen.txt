Break-even and next test
Let C be measured complete cycle wall time and A be committed tokens per cycle, including verification, corrections, rollback, and draft preparation. A candidate wins only if A_new / A_old > C_new / C_old. Head savings hidden behind target work may produce no endpoint gain. Existing hit counts and the current eight-output request do not establish a representative acceptance estimate.

A new treatment must differ from the already tested Q4 head or shorter contiguous prefix. Possible screens include a noncontiguous shortlist or a different low-bit projection kernel. First locate actual retained canonical head inputs or confirmed-token/reverse-hidden payloads, then bind model revision, position, rope, and input hashes. Compare proposal agreement, known target matches, candidate latency, and shortlist construction cost. A terminal state bundle can supply one operator case; it is not a representative sequence. A hidden hash alone is not the raw input. research/continuation-2026-10-25/live-draft-legacy-prefix.json explicitly does not claim raw hidden equivalence. Previous target top-k lists have not been established as available.
