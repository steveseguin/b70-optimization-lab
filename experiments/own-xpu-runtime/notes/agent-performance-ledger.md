# Multi-Agent Performance Ledger (Opus 5.5 + Kimi 3.1 Pro + Codex GPT-6.2-Astra)

Living empirical tracker of agent strengths, weaknesses, hit rates, turnaround times, and failure modes across `experiments/own-xpu-runtime/` (starting with Inkling-2-Mini on 6× Intel Arc Pro B70, expanding to DeepSeek V4.1, Qwen Flash, and future custom-engine lanes).

**Orchestration model:** Coordinator (Gemini) owns git state, `icpx` builds (1 at a time on 15 GiB RAM), 6-card GPU waves (`run-wave.sh` on cards `0–5`), exactness gates (`check-fast.sh` → `check-exact.sh`), `SCOREBOARD.md`, `DO-NOT-REPEAT.md`, and GitHub/neural.download updates. Specialist agents get fresh, scoped, non-blocking tasks matched to their measured strengths.

## Running Lessons for Cross-Model Engine Reuse

Track every technique that generalizes beyond Inkling-2-Mini to DeepSeek V4.1, Qwen Flash, and future B70 engines:
1. **Exact BF16-split DPAS on Xe2 XMX** (Opus): 3-part BF16 split for exact FP32 matrix products on XMX — transfers directly to any Q8_0/Q6_K/NVFP4/INT4 linear/MoE layer on B70.
2. **Online calibrated speculative stopping + plain-streak skip** (Kimi): `INK_SPEC_PLAIN_SKIP` + per-bucket online calibration — architecture-independent, transfers directly to DeepSeek MTP / Qwen MTP / DFlash / Eagle.
3. **One `sycl::context(dev)` per card + `free_memory` pre-check** (Opus): mandatory on 15 GiB hosts with `xe` driver to prevent TTM host-RAM eviction freezes.
4. **6-card parallel wave sweeps** (`scripts/run-wave.sh`, Kimi/Coordinator): run 6 independent single-card trials simultaneously rather than serializing sweeps on 1 card.
5. **Exact-width speculative target attention** (`NT=2,3,5,6,7`, `9485a273ed`, Codex plan + Kimi patch + Codex `nt==1` review): dispatch speculative verification attention by actual live check-row count instead of padding into 4/8-row masked kernels — transfers directly to DeepSeek V4.1 MTP, Qwen Flash MTP/DFlash, and Eagle speculative verifiers.
6. **Zero-conversion ESIMD `int8/Q6 → BF16` `pairs` decode** (`5d2b18794a`, Opus R2): since `float(int8)` has low 16 bits zero, its high 16 bits *are* `bf16(code)` — eliminates 100% of `float→bf16` moves in ESIMD weight unpackers; transfers directly to every Q8_0 / Q6_K / INT8 Xe2 ESIMD kernel across DeepSeek, Qwen, and future models.
7. **In-pass SOA quantized block packing (64-byte aligned codes + packed `uint32` scales)** (`48677594de`, Opus R3): packing 4 consecutive 144-byte quantized steps into 512 B codes (8 aligned cache lines) + 64 B packed scales (1 aligned cache line, 1 `uint32` load/lane) cuts 8 messages / 15 cache-line touches → 5 messages / 9 aligned lines with 0 extra VRAM — transfers directly to NVFP4/MXFP4/Q4/Q8 Xe2 kernels on any model.
8. **Buffer-indexed workgroup-parallel producer fusion (`xd::splite3`)** (`063abfa8d7`, Opus R2 idea + Kimi R3): fuse adjacent independent input-prep kernels by adding a buffer dimension to the grid (preserving exact per-work-item register footprint and 0 SLM) rather than looping inside a thread — transfers directly to any multi-projection pre-split or normalization pipeline.
9. **IGC SYCL `CooperativeMatrix` rule (R2/R4 lessons):** Never put `sycl::joint_matrix` arrays inside non-inlined helper functions called across a `switch` with `group_barrier`, and never declare a 2D `joint_matrix` array with inner dimension `1` (`C c1[2][1]` crashes `ocloc` with `__spirv_AccessChain` on `AS1* AS4*`; flatten to 1D `C c1[2*N]`).
10. **Final-layer live-suffix query pruning on plain prompts (`a131fcb7ab`, Codex R5 plan + Opus R5):** On the last full-attention layer of a prompt without `all_logits`/drafter features, write full K/V to cache as usual, then run query attention only over the live suffix needed by the final logits (last 1 token on standard transformers like DeepSeek/Qwen; last `conv_w + residual` suffix on Inkling-2-Mini) — delivers +5.3% to +6.75% on 100K/200K prompts with 0 new kernels and byte-identical KV caches.
11. **Pipeline-stage-aware split prompt chunk sizing (`cda90b20ae`, Codex R5 plan + Kimi R5 + Codex review + empirical `o/r=160, floor=512`):** Decouple multi-card pipeline chunk scheduling `sqrt(N * (o/r) / (S - 1))` from buffer allocation `T` so prompts shorter than `T` don't serialize across stages and 100K prompts shrink pipeline fill/drain bubbles — delivers **+22–89%** on 3K/31K prompts and **+9.5%** on 6-card 100K with 0 new kernels and 100% bit-identical logits; transfers directly to any pipeline-parallel model.
12. **Per-tensor lossless-layout certification (`F32_HI16`, `6337866d1a`, Codex R7 GGUF census + Opus R7 `src/cert_layout.hpp`):** Certify 100% of elements of high-bandwidth FP32 weights at load time for zero low 16 bits (`(bits & 0xFFFFu) == 0`), pack to `uint16_t`, and reconstruct exact FP32 bit patterns (`bit_cast<float>(uint32_t(h) << 16)`) in place without altering accumulation order or FMA semantics — halved `283.1 → 141.6 MB/token` across 168 Inkling-2-Mini router & loop-control tensors (`−0.344 ms/step`, **+2.7–3.3%** decode, **92.25 tok/s** record, 0 new spills). Directly reusable via `src/cert_layout.hpp` for DeepSeek V4.1, Qwen Flash, and future models!
13. **Bounded-ring dead-prefix drafter skip (`edfd7f95bc`, Codex R7 plan + Kimi R7):** For any speculative drafter whose KV caches are bounded power-of-two rings (max size `Rmax`), whole prompt chunks `[p, p+n)` with `N - p - n >= Rmax` are 100% overwritten in every physical ring slot before the feed ends — skipping drafter feature capture & projection on those chunks (and unlocking final-layer plain-prompt attention pruning on them) yields **+3.7–5.8%** on 100K/200K DSpark prompts with 100% byte-identical target+drafter caches; transfers directly to DFlash/Eagle/MTP drafters with ring caches.
14. **Full final-layer live-suffix pruning with dispatch-family preservation + dead-chunk pipeline carry omission (`137fc13c1c`, Codex R8 plan + Kimi R8 + Codex `!mg[3]` guard):** Extending final-layer prompt pruning past attention through `wo`/MoE/`ffn_tail` while passing the unpruned `dispatch_n` to kernel-family selectors guarantees 0% floating-point family-switch drift (preserving bit-identity across all 8 suffix residues `m=7..14`), and precomputing deterministic `dead_chunk[j]` carry sets lets pipeline stages omit drafter-only `feat_vis` rows over PCIe on dead chunks (`+0.87%` 1c 100K plain across 6/6 cards; `+3.63%` 100K / `+1.74%` 200K on 6c DSpark). Reusable via `src/live_plan.hpp` for any pipeline-parallel speculative model!
15. **Avoid gratuitous SYCL kernel-template bloat on Intel Xe2 / Level-Zero (`f490460478`, R10a V1 vs V2 discovery):** Adding just 2 extra AOT SYCL template instantiations (`3,257 → 3,259` kernels, `+183 KB`) shifted instruction/L2 code layout enough to slow untouched kernels (`moe_down`/`moe_gate_up`/`w:ffn_gate_inp`) by `−0.44%` to `−0.71%` even with all new flags disabled (`V2_OFF`), whereas keeping `3,257` kernels via a runtime uniform predicate (`bool skip` + `sycl::any_of_group(sg, in)`) delivered `+1.00%` DSpark short (`148.84`), `+0.60%` plain short (`92.61`), `+0.40%` 4-seq, and `+0.12%` DSpark 3K. Always A/B candidates against the unpatched installed baseline binary (never only flag-on vs flag-off on the same candidate binary!).

16. **Single-WG packed-scan fused MoE routing + expert grouping (`moe_route_group`, `90f42db342`, Kimi R10b-v2 + Codex subgroup-order fix):** For `2–8` token speculative checks & small multi-sequence batches (`<= 128` experts, `<= 64` total slots), fusing top-k routing with 1-expert-per-lane 64-bit mask popcount + a single packed 7-bit subgroup scan (`active | (cnt << 7) | (nt << 14)`, `288 B` SLM, 2 barriers, 0 spills) eliminates 48 launches/check (`6.88` vs `8.01 µs`, `−0.220 ms/step`) and yields `+1.04%` short DSpark (`150.55 tok/s`), `+0.80%` 3K DSpark (`123.73 tok/s`), and `+1.4%` 4-seq (`160.7 tok/s`) with 100% bit-exactness. Transfers directly to DeepSeek V4.1, Qwen Flash, and any MoE speculative verifier!

17. **Intel ESIMD VC backend `-ffp-contract=off` bug & zero-cost bit-barrier (`XWoQ8<true>`, `de49eb88a9`, Opus R10c + Codex review):** Intel oneAPI 2026.1 VC backend ignores `-ffp-contract=off` on ESIMD `rv + (tot + s) * sc` and contracts it into `mad(rv, tot+s, sc)` (and also folds `fma(o, 1.0f, rv)`, un-barriered SLM store/load, and `((uintptr_t)aligned_ptr & 1u)`). Defeating contraction with a 1-cycle register bit-barrier XORing an opaque host-validated runtime zero (`o_bits ^ (uint32_t)(sc < -1e30f)`) guarantees exact IEEE `mul` + `add` (`0` diffs across all 2,304 rows & all 4 Codex IEEE witness rows, `0` spills) while unlocking `+1.01%` plain 1-token decode across all 6 cards (`93.08 tok/s`, `791 → 743` launches/step). Directly reusable for any ESIMD GEMV+epilogue fusion on DeepSeek V4.1, Qwen Flash, and future models!

18. **Single-combine SLM causal-convolution reuse for speculative checks (`ffn_tail_reuse`, `962831e8ba`, Kimi R11a + Codex review):** Whenever a speculative check (`2–8` tokens) applies a causal convolution (`conv_w = 4`) over an expensive per-token MoE combine (`8` experts × `5` FP32 segments), a single non-template `local = (ntok, 16)` kernel (`128–512 B` SLM, 1 unconditional barrier, `0` spills) computes each rounded `(t, c)` combine **once** instead of up to 4× (`346 → 146` combines, `−77.24 MB/check` avoidable loads), halving `ffn_tail` (`11.28 → 6.05 µs` short, `12.07 → 6.08 µs` 3K, `−0.275..−0.299 ms/check`) and delivering **+1.62%** short DSpark (`152.70 tok/s`) & **+1.18%** 3K DSpark (`125.36 tok/s`) across 6/6 cards with 0 plain regression and 100% bit-exactness!

19. **Bounded live-state batching, direct vector stores & safe closing-barrier elimination in small latency-bound fused kernels (`mix_fused_v`, `11423897cd`, Opus R11b + Codex review):** When a small reduction/mix kernel (96 launches/step) pays serial memory trips and a `9 KB` SLM layout-permutation round trip only needed for a downstream norm, (a) bounding loads to actual live state count in one `float4` batch, (b) returning via direct disjoint `sycl::float4::store` on non-norm launches, and (c) dropping `wg_sum`'s closing barrier whenever the next SLM write is separated by another work-group barrier cuts `mix_norm` (`10.97→9.37 µs`) & `mix_out` (`9.34→7.19 µs`) with `0` new kernels & `0` GRF spills (`−0.192 ms/step`, **+1.69%** plain decode `94.55 tok/s`, **+1.66%** 3K `88.12`, **+0.98%** DSpark `154.13` across 6/6 cards!). 20. **Producer-written ESIMD BF16-split PE parts + `[[no_unique_address]]` zero-spill functor specialization (`PeOut` / `pe_store` / `XDGroupEJ<2/4>`, `ce1f2ea9fa`, Opus R11d + Codex #28):** Emitting 3-part BF16 PE layout directly from the final FP32 attention store (`pe_store` with `tg == 0` zero-padding) removes 48 `xe_split` launches/check (`0.190→0.099 ms`), and guarding optional tail payload members via `[[no_unique_address]] std::conditional_t<HAS_TAIL, EjTail, EjNone>` keeps both `MR=1` (`272 B`) and high-pressure `MR=8` (`272 B`) at **0 spills** and line-for-line identical ASM while fusing causal `attn_tail` inside `MR ∈ {2, 4}` (`−86.9` launches/check, **6/6** short DSpark `155.19 tok/s` & **6/6** 3K DSpark `142.39 tok/s`, 0 plain regression).
