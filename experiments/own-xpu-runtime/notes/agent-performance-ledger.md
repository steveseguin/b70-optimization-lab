## Running Lessons for Cross-Model Engine Reuse

Track every technique that generalizes beyond Inkling-2-Mini to DeepSeek V4.1, Qwen Flash, and future B70 engines:
1. **Exact BF16-split DPAS on Xe2 XMX** (Opus): 3-part BF16 split for exact FP32 matrix products on XMX — transfers directly to any Q8_0/Q6_K/NVFP4/INT4 linear/MoE layer on B70.
2. **Online calibrated speculative stopping + plain-streak skip** (Kimi): `INK_SPEC_PLAIN_SKIP` + per-bucket online calibration — architecture-independent, transfers directly to DeepSeek MTP / Qwen MTP / DFlash / Eagle.
3. **One `sycl::context(dev)` per card + `free_memory` pre-check** (Opus): mandatory on 15 GiB hosts with `xe` driver to prevent TTM host-RAM eviction freezes.
4. **6-card parallel wave sweeps** (`scripts/run-wave.sh`, Kimi/Coordinator): run 6 independent single-card trials simultaneously rather than serializing sweeps on 1 card.
5. **Exact-width speculative target attention** (`NT=2,3,5,6,7`, `9485a273ed`, Codex plan + Kimi patch + Codex `nt==1` review): dispatch speculative verification attention by actual live check-row count instead of padding into 4/8-row masked kernels — transfers directly to DeepSeek V4.1 MTP, Qwen Flash MTP/DFlash, and Eagle speculative verifiers.
6. **Zero-conversion ESIMD `int8/Q6 → BF16` `pairs` decode** (`5d2b18794a`, Opus R2): since `float(int8)` has low 16 bits zero, its high 16 bits *are* `bf16(code)` — eliminates 100% of `float→bf16` moves in ESIMD weight unpackers; transfers directly to every Q8_0 / Q6_K / INT8 Xe2 ESIMD kernel across DeepSeek, Qwen, and future models.
7. **In-pass SOA quantized block packing (64-byte aligned codes + packed `uint32` scales)** (`48677594de`, Opus R3): packing 4 consecutive 144-byte quantized steps into 512 B codes (8 aligned cache lines) + 64 B packed scales (1 aligned cache line, 1 `uint32` load/lane) cuts 8 messages / 15 cache-line touches → 5 messages / 9 aligned lines with 0 extra VRAM — transfers directly to NVFP4/MXFP4/Q4/Q8 Xe2 kernels on any model.
8. **Buffer-indexed workgroup-parallel producer fusion (`xd::splite3`)** (`063abfa8d7`, Opus R2 idea + Kimi R3): fuse adjacent independent input-prep kernels by adding a buffer dimension to the grid (preserving exact per-work-item register footprint and 0 SLM) rather than looping inside a thread — transfers directly to any multi-projection pre-split or normalization pipeline.
9. **IGC SYCL `CooperativeMatrix` rule (R2 lesson):** Never put `sycl::joint_matrix` arrays inside non-inlined helper functions called across a `switch` with `group_barrier` — clang may inline only small `M=1` bodies while leaving larger `M` non-inlined, causing IGC `__spirv_AccessChain` crashes or silent branch skips. Always keep `joint_matrix` bodies directly in `operator()` (or standalone per-width kernels).
