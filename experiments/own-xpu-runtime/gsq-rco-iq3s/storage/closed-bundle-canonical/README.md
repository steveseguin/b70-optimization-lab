# Closed bundle archive aliases

Eighteen older single-member target-state archives have exactly matching member
names, extents and SHA256 values in retained expert-block canonical archives.
The metadata-only appraisal joins all closed independent indices and completed
archive inventories; it predicts532,980,776 bytes of recoverable containers.
No physical verification or release is implied by that metadata appraisal.

The helper imports the unchanged reviewed canonical-container verification and
release bodies. Only its fixed18-row authority and metadata destination change.
Each verification hashes both entire compressed files, reads and hashes every
member, and fsyncs a restoration map retaining original tar metadata. Separate
release rehashes both held files, checks unchanged inode identities, writes a
durable receipt, and removes only the mapped old archive. Canonical archives
remain protected. The member bytes and metadata remain reconstructible; the
old compressed container byte stream is not preserved. Original receipts remain.

Alloperations are root-owned and run after model owners close. No archive work
occurs during measured inference. Floors and model/state precision are unchanged.
