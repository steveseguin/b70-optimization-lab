**Three different claims must stay separate.** Target/MTP equality checks speculative acceptance, rejection and rollback against this same target implementation. Equality to the frozen SC117 target baseline checks that these optimization changes preserve that implementation. Independent same-weight correctness requires a separate, verified implementation reading these exact quantized tensors; neither of the first two excludes a shared target bug. Model quality additionally needs answers evaluated for task correctness and omissions, not just matching tokens. Abliteration/RCO provenance and unchanged tokenizer metadata are not quality guarantees.

**Smallest useful broader follow-up, if root chooses it after the current result:** one persistent pair, three preregistered prompt cases with target/MTP arms and full RESET each: (1) original prompt00 extended to cap512; (2) the existing distinct512-input reading prompt at cap512, after validating its exact tokenizer/template identity; (3) one fixed task-bearing roughly2048-input document with cap128, checked expected facts and position-sensitive retrieval questions. Keep context allocation4096 and model precision unchanged; retain all EOS/low-acceptance cases. This is six requests, not another twelve-prompt campaign or a server-reload chain. Extending prompt00 can bind its first128 tokens to existing evidence, but later tokens and both new prompts need new reference evidence. Existing `NativeController`, RESET, metrics, bundle reader and passive coordinator suffice conceptually; their current fixed-cap/manifests would need a separately reviewed additive adaptation, not a weakened launch plan.

Report cold **request state**/zero reused prompt tokens separately from warm runtime, JIT, weight residency, host page cache and hardware caches. Do not claim the latter are cold, flush them, or infer zero prompt reuse solely from expert-cache counters. A4096 allocation and metadata context262144 prove no usable long-context curve. The suggested2048 case only broadens tested positions inside the admitted4096 capacity.

Before a quality-qualified public SC117 recipe, select a compatible independent same-weight reference and preregister token/logit/teacher-forced comparisons and deterministic decoding details; verify that it supports every actual quant format and graph operation. Existing upstream decoder checks are useful components, not a ready full-model reference. Evaluate the broader outputs against frozen task-specific rubrics or executable checks and inspect complete outputs, including beyond128. Until then, publish at most an expert experimental recipe with explicit same-target-equivalence scope, source/build/model hashes, retained failures and unresolved quality/portable-build gaps. Resident cap128 rates must not be described as a full512-qualified SC117 result, substituted for historical measurements of the different Unsloth model, or used to claim causal cross-session speedup. This note establishes no record or submission eligibility.
