`once.patch` records every change. The native program and compiled inputs stay
unchanged. Its read-only `--plan` hashes the exact native build, independent source
and build review, current plan inputs and27-batch storage completion receipt.

single `gsq-attention-micro-a` unit. No app stop or restore is implemented.

The preserved baseline is `operating/host-after-model-stop.json`: both text units
inactive; vision PID3487303/start63453537 unchanged on BDF27/43. BDF23 must be empty
before launch, is the only allowed native contact, and must be observed held by
the admitted PID/start identity during the run. BDF47 must remain empty. Queue/
PAUSE bytes and boot/fault baseline remain fixed. Ownership/hold markers refuse
admission or latch an incident. Root space and available RAM are monitored.

The child unit has Restart=no, SendSIGKILL=no, KillMode=process, infinite stop
wait/AS, core dumps off, nice19 and explicit native cores. The parent catches its
cooperative signals, latches the first error, and attempts at most one SIGTERM to
the native owner. It continues monitoring uncertain/retained outcomes until unit
exit and a complete passive target drain observation. There is no hard kill or
retry. Positive backend synchronization remains enforced inside the child.

Success additionally requires the84 ordered full-output comparison records,
168 kernel attempts, allocation/transfer bounds and clean teardown. Event samples
are checked against the fixed schedule and baseline output hashes. An unobserved
physical target contact cannot produce qualification success. This does not
promote the interrupted full candidate suite or claim model throughput speed.
