The candidate run is incomplete and not promoted. The controller reported rank receive EOF. Failure and ownership receipts on USB also could not be created. Both native logs report termination after receipt-write exceptions; do not describe these as successful native teardowns.

[Compressed journal](ntfs-journal.jsonl.gz) preserves the exact observed records.

The terminal monitor observed both owners exited and both target cards physically drained. Its fault dictionary remains the same two historical GPU entries; vision is unchanged. No retry, extra signal, reboot, reset, setting change or new GPU request was performed. No complete candidate timing result or speed promotion follows from this interrupted subset.

New GPU work is held. Six retained micro input/output fixtures and all JSON manifests remain accessible. Releasing thousands of file records should address this capacity failure without filesystem repair or touching model weights. No archive/prune has occurred at the time of this incident record. Each archival action requires root review of exact source hashes and restored bytes; future device work requires resolved storage capacity and explicit root admission.
