# GSQ direct packed single-GEMV backend

This is an additive correctness backend for Q4_K, Q5_K, IQ3_XXS, IQ4_XS and Q2_0. Gate and up are separate calls; it introduces no fusion. The `gsqn::submit(Device&, integrated::Matrix&, InputMode, Storage)` facade accepts explicit packed-direct storage, BF16 input/output, shared input for dense/gate/up, and per-slot input for expert down. It rejects unsupported type/layout modes, nontrivial route spans, invalid geometry, short/dead allocations and operand aliases before submission. `Matrix.type` carries the raw GGUF value without changing the sealed enum definition. The explicit storage assertion is a caller contract; bytes alone cannot distinguish packed weights from a mislabeled table or expanded allocation.

An Engine overlay can define `GSQN_RUNTIME_HEADERS_PROVIDED` after including its own consistent checked runtime closure (`integrated::Matrix`, HostOperation or SyclOperation, Device, prepared_submit and packet26 guard). This suppresses the standalone inherited-header includes and prevents duplicate iq3 definitions; the scalar equation copy is unchanged. That integration must pin its actual supplied headers.

The operation preserves the existing route convention: valid rows occupy their original slot, valid zero-length and unused tails produce canonical BF16 NaN, invalid routes produce status1 and NaN output; valid route status is0. It has no shared sticky-error writes. Engine-level active/error admission remains the caller's responsibility. Finite-scale numerical parity is the target; native NaN payload parity is not claimed.

`device_formats.hpp` is the frozen CPU-proven adapter with exactly one include replaced: the checked inherited runtime already defines `iq3`, so including the original physical copy again would redefine it. The build verifies this exact delta. The five kernels use a shared strided32-lane accumulation and adjacent reduction tree. The Host body executes through existing Device/Arena capture and the unchanged Host/LifetimeMock/MockDevice backend; its event markers are simulated. Native uses `SyclOperation` and `prepared_submit`, by-value bound pointers/shape/dependencies and the selected in-order queue. Neither path owns indirect table payloads; cache/zero-copy table integration is explicitly pending.

The CPU fixture covers every type in dense, shared routed and per-slot routed modes, with ten route slots, nonzero row beginnings, invalid experts, zero counts and tails. It compares all outputs/statuses to the frozen scalar function, then changes live activation and weight bytes, verifies captured caller metadata cannot redirect writes, checks alias/extent/type/shape refusals and stale-generation refusal. Each owner must close with zero live bytes/events. These are kernel ABI tests, not full layer or model tests.

Builds are separate and require source review. The CPU command is:

```sh
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 MKL_NUM_THREADS=2 taskset -c 8-15,24-31 nice -n 19 python3 -B experiments/own-xpu-runtime/gsq-rco-iq3s/native-formats/build.py --cpu
```

`--plan-native` prints a compile/link plan without invoking a compiler or ELF. `--compile-native` is reserved for separate coordinator admission under the existing low-memory compiler protocol. Its public main always returns64; the future submit entry is retained only for offline inspection. The helper never invokes the native binary. Full source/object pins, attempts and failures are preserved; native kernel symbols, image and main disassembly are checked offline after compilation. No model bytes are read by either path.

Validation: first CPU attempt passed **15 cases, 60 checks and 100 refusals**, with fifteen clean Host owner receipts, 35 dependency files and 23 reused Host objects. The [CPU receipt](evidence/cpu-proof.json) retains all case output hashes and owner closure fields. The first [native compile-only attempt](evidence/native-compile.json) passed with 44 dependency files and 33 reused native objects; offline inspection found all five `PackedKernel` entries, the retained future submit symbol, and public main returning64 with no call to that future entry. Neither the produced ELF nor a GPU API was invoked. Both exact source snapshots, commands, logs, binaries and offline image artifacts remain under the ignored attempt paths recorded in the receipts. No failed attempt occurred. Total current packet storage is below 50 MiB. This does not enable Engine model loading, expert-cache tables, BF16 HC fallback, F16 PLE conversion, MTP, or a device run.

The separate [native qualification runner](../native-qualification/README.md) subsequently passed all15 bounded GPU cases/45 kernel executions on BDF23. That runner uses this exact facade; it does not change the historical compile-only executable or establish full-model inference.
