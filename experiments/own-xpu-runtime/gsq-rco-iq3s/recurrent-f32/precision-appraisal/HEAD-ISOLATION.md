A diagnostic head operation can retain the exact FP32 value immediately before the existing final BF16 conversion while still writing the original BF16 logits for the existing argmax. This attributes only the final storage-rounding difference. It does not upgrade upstream activations or silently change the token oracle.

It needs real allocation/extents/live-binding checks and an exact output.weight selector.
