# Qwen3.8 27B Q8 TP2 oneAPI 2026.1.1 compiler refresh

Date: 2026-08-16

Status: closed as performance-neutral; do not repeat unchanged.

## Hypothesis

The accepted AOT SYCL library was built with Intel oneAPI DPC++/C++ 2026.1.0
(`20260617`). The post-update host now provides 2026.1.1
(`2026.1.1.20260724`, package `2026.1.1-325`). A clean rebuild can change code
generation across every hot Q8, recurrent, attention, and collective kernel
without changing source arithmetic.

This arm is intentionally narrower than an upstream-source refresh. Fresh
remote audit found upstream at `4df29be4f`, but its post-base GDN cache fusion
is already subsumed by the accepted direct-state path and its generic
unary-plus-multiply fusion has no remaining unfused target in the accepted
one-token trace.

## Contract

- identical accepted source tree and source patch;
- identical Release configuration: GNU C, Intel `icpx`, SYCL Intel target,
  `bmg_g31` AOT, F16 on, Level Zero API on, graph/DNN/host-memory fallback
  off, and CURL off;
- clean build with compiler 2026.1.1, no imported objects from the accepted
  build;
- no fast-math, arithmetic, runtime-door, model, selector, split, KV, flash
  attention, batch, or ubatch change;
- build at no more than two jobs under the established 8 GiB memory cap;
- prove the candidate library embeds 2026.1.1 and capture hashes;
- require byte-exact fixed completion before a same-binary-equivalent
  position-balanced screen;
- promote only after repeatable gain and the complete quality contract.

Stop on any device-lost, reset, hang, timeout, or output mismatch.
