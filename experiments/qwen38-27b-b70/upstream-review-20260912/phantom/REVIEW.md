- `data/2026-09-03-qwen38-fp8-r156-mtp2-phantom-handoff-logging-r170-result.json`: sampler emitted `[[60]]`, valid count 1, host copy `[[60]]`, scheduler appended `[60]`. This directly contradicts “the model never generated” and a token fabricated in host handoff. The discarded preceding async step is an observed association, not an established cause. The summary's conclusion that KV/recurrent state was sound is interpretation rather than an exhaustive state proof.
- `data/2026-09-03-qwen38-fp8-r156-mtp2-phantom-logits-row-r171-result.json`: `logits_indices=[30]`, GPU/CPU query bounds `[0,31]`; row 30 top tokens `[60,26]` at 14.82/13.95. An ordinary off-by-one selection was rejected in that run. It does not establish why the logits changed, or prove that a token's contribution was missing.
- `data/2026-09-03-qwen38-fp8-r156-mtp2-phantom-block-trace-r172-result.json`: affected first prediction changed to 220 (17.39), with 60 second (14.77). “Always the prompt's last token” is false for the diagnostic family. Block reuse also occurred at a clean boundary; reuse alone was insufficient.
- `data/2026-09-03-qwen38-stock-f01e-mtp2-phantom-r192-result.json` and its matching note: default-compile async-on pass had no first-token anomaly; async-off had cache-c032 beginning `[60,271,3833]`. The JSON is a token comparison summary, not a complete provenance bundle or sampler trace. Numerous later-token differences coexist.
- `data/2026-09-03-qwen38-stock-f01e-mtp2-phantom-repeats-r194-result.json`: additional compiled async-on/off passes had no anomaly; two eager async-on passes had cache-c040 beginning `[60,271,3833]`. The six-pass total is three observed affected requests in 384 requests across different server configurations, not a stable estimated probability of one in 64. Two eager observations mean compilation is not a necessary condition for the stock symptom; one async-off observation means async scheduling is not necessary either. They do not prove a shared underlying mechanism across configurations.
- The R192/R194 note infers “inserted into output stream without being in model context” from 16–18 tokens of aligned tail. That inference is invalid: similar continuation does not prove absence from context, and R170 explicitly records legitimate downstream handling of sampled 60. Preserve the tail alignment only as an observation, if raw outputs support it.
- `notes/2026-09-03-qwen38-fp8-mtp2-phantom-layer-trace-r182-result.md`: per-layer instrumentation removed the anomaly and changed other outputs. Equal traces in these instrumented passes cannot exclude all model layers in the original failing execution. Avoid “bit-identical GDN inputs/outputs for all requests” unless the precise tensors and unchanged failing execution are separately evidenced.
- `notes/2026-09-03-qwen38-fp8-mtp2-phantom-inductor-knobs-r184-result.md`: R186n has the token-220 variant despite an empty token-60 detector; the final-norm comparison records last-row absolute sums and rank disagreement. - R187/R190 whole-graph depth-2 and R191/R193 depth-3, plus September 4 R197 depth-4 notes, report clean sequential passes. These are bounded local-build controls, not a proven upstream fix or proof the stock symptom is piecewise-specific.

## Filing threshold

Historical evidence is sufficient for a candid exploratory report, provided it clearly says September 3, includes the contradictory diagnostics above, and offers an executable exact prompt suite with raw token outputs. It is insufficient for the existing definitive causal wording. As presently packaged, the draft has a suite-link placeholder and only summary links; withhold filing until that reproducibility gap is closed. Fresh GPU access is not inherently required to report history, but is required to claim reproduction today and is the preferred next step if raw historical artifacts cannot be recovered.

Before a fresh report, preserve the exact model revision, immutable image digest, actual launch/environment logs, full ordered prompts and response token IDs, then run matched repeated MTP0/MTP2 controls. Separate compile and async arms explicitly. Inspect first-step logits and sampling only after reproducing the uninstrumented symptom, because probes can change it. Do not treat greedy cross-run differences alone as proof of a specific bug in this numerically nondeterministic stock lane.
