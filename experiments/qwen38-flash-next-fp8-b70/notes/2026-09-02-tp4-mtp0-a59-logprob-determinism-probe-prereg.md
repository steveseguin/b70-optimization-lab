# Qwen3.8 Flash-Next FP8 A59 logprob-resolution determinism probe preregistration

Date: 2026-09-02
Status: diagnostic; frozen before launch; no promotion claim possible

## Question

A58 showed the full-graph TP4/EP4 MTP0 line producing different greedy
outputs for identical requests at every prompt depth from 256 to 2048. Does
the nondeterminism already exist in the first decode step after prefill, or
does it enter in the graph-replayed continuation, and how large is it?

## Design

- Server: byte-identical to A56/A57/A58 (tuned M1 W13-N32 map, `twoshots`,
  full decode graph `[1]`, external checkpoint, PLE-only UVA placement,
  2304 max model length, host guards) at attempt 59 / port 19731,
  generated by `tools/rewrite-q38-a58-to-a59-logprob-probe.py`:
  launcher `8e4ebce7...`, client `4204d28d...` (frozen, not executed),
  supervisor `770d9fc4...`, host wrapper `a3599e92...`. GuC 70.72.1.
- Client: `tools/probe-q38-a59-logprob-determinism.py`. For depths 256 and
  2048 (first N token ids of the frozen fixture case `a173e60e...`):
  1. eight identical greedy requests with `max_tokens=1`, `logprobs=5`:
     the first decode step's top-5 tokens and logprobs must be compared
     bitwise across repeats;
  2. three identical greedy requests with `max_tokens=128`, `logprobs=2`:
     first divergence index, maximum absolute top-1 logprob difference over
     the positions before the divergence, and the top-1/top-2 gap at the
     divergence in repeat 1.
- Output: `<run_dir>/a59-logprob-determinism.json`; the probe writes the
  supervisor stop file afterwards (invalid stop expected, rc 143/70).

## Reading

- First-step top-5 identical on all eight repeats, jitter only later:
  prefill and the first decode step are exact; the graph-replayed decode
  path carries the nondeterminism. Next: an eager control server with the
  same identity minus the graph.
- First-step top-5 already differ: prefill (chunked 64-token) and/or the
  collective path is nondeterministic. Next: toggle `twoshots`/public
  oneCCL and chunking on fresh servers.
- The magnitude (logprob spread, gap at divergence) says whether this is
  last-ulp accumulation-order jitter or something larger.
