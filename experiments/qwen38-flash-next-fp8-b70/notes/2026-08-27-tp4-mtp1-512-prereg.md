# Flash-Next TP4 MTP1 configured-512 preregistration

Date: 2026-08-27

## Purpose and preservation boundary

This is the first bounded native-MTP arm for the official Flash-Next FP8 child
artifact. It fills the TP4/eager/MTP1/text/zero-context cell only if the target
identity, quality, and complete-response gates pass. It does not replace or
lower any captured MTP0 result.

The source rebase already contains the Qwen4Exp MTP model, config conversion,
dedicated proposer, multi-owner cache mapping, and XPU dispatch. The remaining
stale interface was isolated to its tests: the current cache API names
`tokens_per_state` and `num_states`, while four Qwen proposer tests still used
the removed `compress_ratio` and `storage_block_size` fields. Source commit
`44fb789db880d808161a46311a65d3eafa0e3032` changes those three test references
only. The combined config/model/proposer/reference battery passes 58 tests with
27 hardware-specific skips. Runtime code and the accepted MTP0 performance
path are byte-unchanged by that commit.

Durable source delta:
`patches/qwen38-flash-next-fp8-b70/vllm/0017-Port-Qwen4Exp-MTP-tests-to-tokens-per-state-cache-AP.patch`
(SHA-256 `cdd9631a9480ab333fb4340812adf856ad65e22b0c4da1b1a8ef91bb04d7fa3c`).

## Frozen gates and order

1. Require the exact source/model/runtime hashes, clean source trees, four-card
   preflight, exact 12.22-GiB placement receipts, reported maximum 512, and at
   least 512 cache tokens. A load or fit failure stops the arm; do not silently
   change placement, cache, precision, or target performance settings inside
   attempt 1.
2. Require a healthy models endpoint and confirm the server identity records
   MTP1. Run the fixed-set short/repeat battery before timing. The seven short
   outputs and 16/16 repeat output must match the accepted MTP0 protocol-v2
   baseline. A small in-capacity needle is capability evidence only; it is not
   compared to a different-depth baseline.
3. Only after quality parity, run three p128/o256/c1 rows with the hardened
   comparison helper. Require exact 146/256 usage, nonempty text, internally
   consistent usage, and the accepted target output hash
   `5f40744644b98ddd58a0c202fe855af324c0b1c33e1a6275afd74c12488f89f0`.
4. Report the three-row median separately from the MTP0 median
   `5.221849709 tok/s`. A slower valid MTP1 result is still useful matrix
   coverage, but it cannot supersede or relabel MTP0. Retain any available
   draft/acceptance counters as secondary evidence.
5. Stop normally and retain identity, logs, request order, raw JSON, hashes,
   and shutdown state. Any incomplete response is a failed row after helper
   commit `08a865143`; it cannot become a zero-rate or successful sample.

If attempt 1 fails only because the added MTP weights do not fit, the next arm
must preregister an explicit MTP-only placement change and compare its target
speed against this unchanged-placement control. No automatic retry or broad
offload expansion is authorized.

## Attempt 1 result and attempt 2 amendment

Attempt 1 was executed without changing the frozen identity. It proved that
the complete target plus native MTP1 draft fits on TP4: all four ranks loaded
the 131 shards, reported 32.06 GiB for the combined model, and allocated an
870-token cache. Startup then reached the speculative warmup and stopped at
the intentionally fail-closed legacy adapter, which accepted the preserved
23-argument target operator but rejected speculative metadata. No API request
or speed sample was produced, so this result does not alter any MTP0 capture.

## Attempt 2 result

Attempt 2 passed startup, the healthy API gate, complete-response accounting,
and real MTP engagement. All 29 periodic speculative-metrics windows reported
positive accepted and drafted counts, with reported acceptance between 60%
and 100%. It then failed the prerequisite MTP0 output-parity gate: only one of
seven inherited exact cases passed, the fixed-set repeat produced three output
hashes, and every normalized exact output differed from the accepted MTP0
baseline. The responses were complete and coherent but exposed reasoning text
instead of preserving target-only greedy output. No speed row was run.
