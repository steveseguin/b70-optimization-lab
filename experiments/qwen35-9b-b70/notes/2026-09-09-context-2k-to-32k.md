# Context 2K to 32K: lossless throughout, and one column that is not a curve (2026-09-09)

Campaign `x32k`, Qwen3.5-9B W4A16, TP1, one B70 on `steve-b70s`, real-content depth ladder,
`max-model-len 33024`. The MTP0 arm runs first and becomes the oracle; the MTP3 arm is compared
against it token-for-token at every depth. Both arms reported `status: passed`.

| active context | MTP0 tok/s | MTP3 tok/s | speedup | MTP3 TTFT ms | gates | exact vs oracle |
| ---: | ---: | ---: | ---: | ---: | --- | --- |
| 2,048 | 62.92 | 111.41 | 1.77x | 702 | pass | **yes** |
| 4,096 | 62.19 | 139.16 | 2.24x | 1,360 | pass | **yes** |
| 8,192 | 61.15 | 113.89 | 1.86x | 2,729 | pass | **yes** |
| 16,384 | 59.51 | 147.97 | 2.49x | 5,578 | pass | **yes** |
| 24,576 | 57.86 | 129.33 | 2.24x | 8,576 | pass | **yes** |
| 32,768 | 56.41 | 86.68 | 1.54x | 11,731 | pass | **yes** |

## What is solid

**Speculation is lossless at every context depth from 2K to 32K.** Every point is byte-exact against
its same-configuration MTP0 oracle. That closes the context dimension of the campaign's mandate.

**The MTP0 column is a genuine curve.** It is monotone and shallow: 62.92 -> 56.41, **-10.3% across a
16x increase in context**. On a 32 GiB card with an 11 GB checkpoint the KV budget is not the
constraint, and long context is close to free for decode. TTFT scales about linearly with context,
as prefill should.

## What is not a result

**The MTP3 column is not a context curve and must not be plotted as one.** Three samples per depth,
and speculative throughput depends strongly on how predictable the continuation is: 139 at 4K, then
114 at 8K, then 148 at 16K is acceptance variance across prompt classes, not a property of context
length. Quoting a shape from it would be the selected-fixture error in a different disguise.

The 32K point (86.68, 1.54x - the lowest speedup on the ladder) is the one plausibly real effect,
since longer and more diverse history should lower draft acceptance. At n=3 it cannot be separated
from the same variance. **A repeat at 32K with the full suite is queued as the way to settle it.**

Note the MTP3 2K point (111.41) agrees with the strict suite's depth-3 figure (110.69) measured on a
different server pair, which is a useful cross-check that the depth ladder and the strict lane are
measuring the same thing.
