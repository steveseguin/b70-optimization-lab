# R293 on the 9B: the FP16 linear chunk tax was here too

2026-09-11, chain `scripts/run-20260911-qwen35-9b-classpad-chain.sh`, data
`data/2026-09-11-qwen35-9b-r293-classpad.json`. Background and the mechanism:
`experiments/qwen35-4b-b70/notes/2026-09-09-the-fp16-linear-chunk-is-a-throughput-tax.md` and
`experiments/qwen35-4b-b70/notes/2026-09-11-r293-class-consistent-fp16-linear-on-the-server.md`.

The 9B runs the same R224 op on the same base image with a 2 GB fp16 vocabulary projection (248320 x 4096),
so every 32-row piece re-read 2 GB. The R224 one-card depth-3 column was flat from c16 (747, 827, 787 tok/s
at c16/c32/c64) while no-speculation reached 1273 at c64; that flatness was the tax. Seven arms on the R293
image with `VLLM_XPU_FP16_LINEAR_CLASSPAD=1`, every container verified:

| | R224 | R293 |
| --- | ---: | ---: |
| G1/G2/G3, one card and two | 12/12 | **12/12** |
| one card, depth 3, c64 | 787 | **1225** |
| one card, no spec, c64 / c128 | 1273 / 1324 | **1644 / 1955**, exact |
| two cards, depth 3, c64 | 1465 | **2165** |
| two cards, no spec, c64 / c128 | 2093 / - | **2614 / 3227**, 512/512 at c128 |
| two cards, no spec, 5 ms stagger, tie-site suite c64 | 1257/1280 at 2095 (unstaggered) | **1280/1280 at 2557**, certified |
| single user, depth 3 / MTP0, one card (strict) | 113.6 / 64.3 | 112.4 / 61.7 |
| single user, depth 3 / MTP0, two cards (strict) | 172.3 / 97.6 | 164.7 / 93.6 |

Identity is R224's at every rung within the four-pass resolution. The staggered-admission recipe, found
on the 4B, had never been measured on this lane; it is byte-exact here as well. Single user costs 1-4%, less
than the 4B's 5-6%, because this model's per-layer projections are a smaller share of its step.

Two modes on one image, both lossless: the switch off for the published single-user headline, on for any
server above about eight users. Under R293 depth 3 leads no-speculation to about c32 on one card.

Not measured: the 27B INT4 lane, which runs the same op; its published c16-to-c32 collapse was attributed
to the W4A16 GEMM while this tax sat underneath it.
