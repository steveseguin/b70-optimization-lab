# Build Photo Assets

These images are local copies of public build photos shared from Steve's X feed and are used in the community/build documentation to illustrate physical setup considerations.

Sources:

- `b70-build-photo-01-source.jpg`: https://pbs.twimg.com/media/HHtRNbNW4AQNUNv?format=jpg&name=medium
- `b70-build-photo-02-source.jpg`: https://pbs.twimg.com/media/HI9wPxuW0AEsJoP?format=jpg&name=4096x4096

When adding more photos, prefer small compressed copies with captions. The docs should explain what the photo demonstrates: spacing, airflow, power, risers, slot order, storage, cooling, or diagnostics.
