Each fresh load runs twelve cold suite prompts and one distinct 512-input-token prompt, with one user and a 4096-token context allocation. Decode is the class-balanced first-100-token generation rate across the twelve suite prompts. Each reading row measures one 512-input-token request on the warm runtime; native TTFT includes first-token work. Two-card TTFT starts after the request-state reset. The independent oracle covers only the first 128 output tokens; full-output quality remains pending. The CPU oracle uses the custom BF16 recurrent-state contract. Even first-128-token agreement does not establish equivalence to reference FP32 recurrence or no additional quality loss.
