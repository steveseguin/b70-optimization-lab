# Measured rolling policy preserves both cold requests

The separate measured-policy process completed both 87-token/32-output requests
on four cards and exited zero on every worker. Both requests match all 2,065
target buffers, all 73 canonical draft allocations and all output IDs against
both the accepted baseline and the prior full-diagnostic qualification.
Native binary `02a47c059444` and the corrected execution controller are unchanged.
No draft training or host setting changes were made.

The native receipts report zero target/provider byte-verified restores, false
aggregate byte-verification flags, and empty provider-survival traces. Mandatory
checked copies, host restoration, error checks, epoch/request isolation, global
wire continuity and actual proposal provenance remain active and passed. The
final full-state comparisons establish parity separately; omitted per-operation
checks are not claimed as performed.

The independent review verified 34 runtime pins, 228 native source pins, 68
small state metadata hashes and ten qualified raw seal identities. All 88
passive samples retain the same 14 historical fault signatures; minimum available
memory was 65,628,450,816 bytes. Final worker exits are separately established
by terminal return codes. Both prediction miss depths occurred, but provider
borrowing at pending depth two was not observed.
