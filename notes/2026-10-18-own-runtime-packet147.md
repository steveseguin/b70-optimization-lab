fusion. The current 29.260 run still uses the older HC path. The failed
route/recurrence port did not test this change. Older engine receipts support

record spends **1.23 ms/token** rebuilding and publishing the full table at a
safe boundary. The old 144-to-one upload improvement is already included.

to reach 2%. It merits a small feasibility brief, not a promised speedup.

wrong guess, with a new exact execution graph and explicit communication costs.

projects only **+1.62%** on the faster 29.26 baseline before new costs. The more
favorable +11.7% scenario still assumes away unmeasured work.
